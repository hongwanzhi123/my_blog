# 个人博客

欢迎来到我的个人博客。这里主要整理我的算法学习笔记、计算机视觉知识体系，以及项目实践总结。内容会持续更新，后续我也会将部分 Markdown 文档整理为 PDF 版本，方便归档与展示。

## 博客定位

这个博客主要服务三个目标：

1. 系统沉淀算法设计方法，形成可复用的题解思路。
2. 梳理计算机视觉方向的核心模型、任务脉络与工程经验。
3. 总结真实项目与竞赛实践，积累可讲述、可展示、可复盘的项目资产。
