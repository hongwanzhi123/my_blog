# 算法设计方法总结

这一部分主要整理算法学习中的高频题型、经典解法与建模思维。相比单道题解，更关注方法的抽象与复用，目标是形成“看到一类题就能快速判断做法”的题型体系。

## 模块 1：动态规划

这是算法学习中最值得系统整理的一类方法，重点在于状态定义、转移方程、初始化和优化。

- 对应笔记：`/动态规划.md`
- 适合内容：一维 DP、网格 DP、背包 DP、区间 DP、树形 DP、股票问题、字符串 DP
- 整理重点：后续可整理为一份完整 PDF，作为算法方法部分的核心文档

### 可补充的整理点

- 如何判断一道题是否适合用动态规划
- 常见状态设计套路
- 从记忆化搜索到递推优化的思路
- 时间复杂度与空间压缩技巧

## 模块 2：搜索与回溯

这部分适合归纳 DFS、BFS、状态搜索、剪枝与回溯模板，尤其适合组合枚举类题目。

- 对应笔记：`/回溯.md`、`/图论（搜索）.md`
- 适合内容：排列组合、子集问题、网格搜索、图搜索、剪枝策略
- 整理重点：强调“搜索树如何画”“剪枝为什么有效”

## 模块 3：分治与枚举

分治与枚举虽然基础，但在很多题目中是复杂思路的起点，适合整理成“暴力到优化”的思维演进过程。

- 对应笔记：`/分治.md`、`/枚举.md`
- 适合内容：二分思想、递归分解、区间拆分、暴力优化、分类讨论
- 整理重点：突出“如何从直接做法走向更优做法”

## 模块 4：图论与树结构

这部分适合整理树、二叉树、图遍历以及结构化搜索问题，作为算法结构理解的重要补充。

- 对应笔记：`/二叉树.md`、`/图论（搜索）.md`
- 适合内容：树的遍历、路径问题、层序处理、图建模、连通性问题
- 整理重点：用结构图辅助说明思路会更清晰

## 模块 5：基础数据结构

基础数据结构是很多算法题的落点，适合作为知识总结中的入门部分，帮助学习者建立整体感。

- 对应笔记：`/链表.md`
- 可继续扩展：栈、队列、哈希表、堆、并查集
- 整理重点：每类结构用“定义 + 操作 + 常见题型”组织内容
