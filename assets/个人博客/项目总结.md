# 项目总结

这一部分主要整理项目与竞赛中的实践经验。相比知识笔记，这里更强调任务背景、方案选择、训练流程、结果分析和工程落地。

## 模块 1：下水道异常检测项目

该项目可以作为视觉项目总结中的核心案例。

- 对应笔记：`../下水道异常检测笔记/下水道异常检测.md`
- 可展开内容：
  - 业务背景与问题定义
  - 数据来源与缺陷类别
  - 为什么选择目标检测或分割模型
  - 训练流程、评估指标与误检漏检分析
  - 实际部署场景与工程限制

## 模块 2：Kaggle 练习项目

Kaggle 项目适合整理基础建模流程、数据处理方法和实验对比思路。

- 对应笔记：
  - `../下水道异常检测笔记/计算机视觉/Kaggle/手写数字识别.md`
  - `../下水道异常检测笔记/计算机视觉/Kaggle/泰坦尼克号.md`
- 可展开内容：
  - 从数据清洗到特征构造的流程
  - 基础模型选择与调参方法
  - 结果分析与 leaderboard 思维

## 模块 3：训练流程与实验管理

这一模块不一定对应单一笔记，但很适合在知识总结里单独提炼出来，体现工程化思维。

- 整理内容：
  - 数据集划分策略
  - 数据增强方案
  - 损失函数与指标设计
  - 训练日志、实验对比与结果记录
- 可关联资料：
  - 图像分类训练笔记
  - 图像分割训练笔记
  - 模型蒸馏相关笔记

## 模块 4：模型部署与推理优化

该模块用于区分“训练出模型”和“让模型稳定运行”两个阶段。

- 相关资料：`../下水道异常检测笔记/计算机视觉/模型部署/ONNX _ONNX Runtime.md`
- 整理内容：
  - PyTorch 到 ONNX 的导出流程
  - ONNX Runtime 推理部署
  - 模型体积、延迟、显存占用与精度平衡
  - 面向 CPU 或边缘设备的优化思路

## 模块 5：项目总结与方法迁移

该模块用于总结项目经验如何迁移到新的任务中。

- 整理内容：
  - 从分类任务迁移到检测任务的方法变化
  - 从学术模型选择到工程模型选择的判断标准
  - 项目中踩过的坑与解决方案
  - 后续优化方向与可扩展能力

## 知识要点

- 从业务问题抽象成建模任务的能力
- 独立完成训练、评估、优化与部署的能力
- 将学习型笔记转化为项目型成果的能力
- 结构化表达项目经历的能力
