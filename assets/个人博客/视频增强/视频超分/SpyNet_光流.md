# SPyNet 光流

SPyNet，全名是 Spatial Pyramid Network，是一个用于估计 光流 optical flow 的轻量级网络。它的核心思想是：不要让一个大网络一次性估计所有大运动，而是借鉴传统光流里的金字塔 coarse-to-fine 思路，在低分辨率先估计大致运动，再逐层上采样、逐层修正。 原论文题目是 Optical Flow Estimation using a Spatial Pyramid Network，作者把它描述为“将经典空间金字塔光流框架和深度学习结合起来”的方法。

## 1. 先理解什么是光流

光流就是描述相邻两帧之间像素运动的二维位移场。

假设有两帧图像：

I1：前一帧
I2：后一帧

光流 F_{1→2} 表示：

I1 中每个像素，在 I2 中移动到了哪里

每个像素都有一个二维向量：

F(x, y) = (u, v)

其中：

u：水平方向位移
v：竖直方向位移

例如：

F(100, 50) = (3, -2)

表示第 1 帧中 (100, 50) 这个位置的内容，在第 2 帧中大约移动到了：

(103, 48)

在视频超分、视频去噪、视频去模糊里，光流最大的作用是：把其他帧的内容对齐到当前帧。

比如你要恢复第 t 帧，可以用第 t-1 帧的信息，但必须先知道第 t-1 帧里的物体移动到第 t 帧哪里了。否则直接融合多帧会出现重影、模糊、边缘错位。

## 2. SPyNet 想解决什么问题

早期深度光流模型，比如 FlowNet，直接用一个较大的 CNN 从两张图预测完整光流。SPyNet 的观点是：大运动不一定要靠大网络硬学，可以交给图像金字塔处理。

原论文中明确说，SPyNet 在每个金字塔层级上先用当前光流估计去 warp 图像，然后让一个小网络预测光流更新量；由于大运动已经被金字塔分解，每一层网络只需要处理较小的残余运动。论文还强调，SPyNet 相比 FlowNet 参数量小约 96%，因此更高效、更适合嵌入式应用。

一句话：

SPyNet = 传统 coarse-to-fine 光流思想 + 小 CNN 残差修正。

## 3. SPyNet 的整体流程

SPyNet 的流程可以画成这样：

输入两帧图像 I1, I2
        ↓
构建图像金字塔
        ↓
从最粗尺度开始：
    初始化光流为 0
        ↓
    用当前光流 warp I2
        ↓
    小 CNN 预测残差光流 ΔF
        ↓
    当前光流 F = F + ΔF
        ↓
    上采样到更高分辨率
        ↓
逐层细化
        ↓
输出最终光流

它不是一次性预测最终光流，而是逐层 refinement：

低分辨率：估计大致运动
中分辨率：修正中等运动
高分辨率：修正细节和边缘

这和传统光流方法非常像，只不过传统方法在每层解优化问题，而 SPyNet 在每层用 CNN 预测更新量。论文摘要中也说，它不是在每个金字塔层级做标准目标函数最小化，而是训练一个深度网络来计算光流更新。

## 4. 为什么要用图像金字塔

假设原图中一个物体移动了 32 个像素。直接在原分辨率估计，这就是一个大位移，对 CNN 来说比较困难。

如果把图像缩小 4 倍，那么这个运动就变成：

32 / 4 = 8 像素

如果缩小 8 倍，就变成：

32 / 8 = 4 像素

低分辨率下，大运动会变成小运动，更容易估计。

所以 SPyNet 的思想是：

先在低分辨率估计大方向
再回到高分辨率修细节

这就是 coarse-to-fine。它的优势是：每一层的小 CNN 不需要处理很大的位移，只需要预测当前尺度下的残余小位移。

## 5. 每一层到底输入什么

在每个 pyramid level，SPyNet 通常会输入三类东西：

1. 当前尺度的参考图像 I1^l
2. 用当前光流 warp 后的目标图像 warp(I2^l)
3. 当前上采样来的光流 F^l

然后小网络输出：

残差光流 ΔF^l

最后更新：

F^l = F^l + ΔF^l

BasicSR 文档里的 SPyNet 基础模块也体现了这个设计：模块输入是 8 通道，包括参考图像 3 通道、邻近图像 3 通道、初始光流 2 通道，输出是 2 通道光流。

为什么是 8 通道？

参考图像 RGB：3
被 warp 的邻近图像 RGB：3
当前光流：2
总共：8

所以 SPyNet 的小 CNN 不是凭空估计光流，而是看：

当前图像长什么样
对齐后的另一帧还差在哪里
当前已有光流是多少

然后预测一个修正量。

## 6. 为什么要 warp 第二帧

这是理解 SPyNet 的关键。

假设你已经有一个粗略光流 F，可以用它把第二帧 I2 warp 到第一帧 I1 的坐标系下：

I2_warp = warp(I2, F)

如果当前光流很准确，那么：

I2_warp ≈ I1

如果还不准确，那么两者之间会有差异：

I1 和 I2_warp 的差异 = 光流还需要修正的地方

所以 CNN 只需要看这个差异，然后预测残余光流。

直观理解：

原本问题：
直接从 I1 和 I2 估计完整运动

SPyNet 的问题：
I2 已经被粗略对齐了，只需要估计还差多少

这会让任务简单很多。

## 7. SPyNet 的一层计算可以这样理解

对于第 l 层金字塔：

输入：
I1^l, I2^l, F^{l+1}

第一步，把上一层更粗尺度的光流上采样到当前尺度：

F_up^l = upsample(F^{l+1}) × 2

为什么要乘 2？因为分辨率放大 2 倍后，像素位移单位也要放大 2 倍。

第二步，用这个光流 warp 第二帧：

I2_warp^l = warp(I2^l, F_up^l)

第三步，把它们拼起来：

concat(I1^l, I2_warp^l, F_up^l)

第四步，小 CNN 预测残差：

ΔF^l = G_l(concat(...))

第五步，更新当前光流：

F^l = F_up^l + ΔF^l

最后到最高分辨率时，F^0 就是最终光流。

## 8. SPyNet 的“小 CNN”长什么样

SPyNet 每一层用的是比较小的卷积网络。它不像大型光流模型那样堆很深的 encoder-decoder，而是在每个金字塔层级上使用一个轻量 CNN 来预测 residual flow。

原论文强调，SPyNet 的每个网络不需要处理大运动，因为大运动由 pyramid 处理；因此整体模型可以做得很小，并且相比 FlowNet 参数少很多。

你可以把每一层的 CNN 理解成：

8 通道输入
    ↓
几层 7×7 或 3×3 卷积
    ↓
2 通道输出

输出 2 通道就是：

水平残差位移 Δu
竖直残差位移 Δv

## 9. SPyNet 和传统光流的关系

传统光流一般有这些经典假设：

亮度一致性：同一个点在相邻帧亮度不变
空间平滑性：邻近像素运动相近
金字塔策略：从粗到细估计大运动

SPyNet 保留了 金字塔 + warping + refinement 这个经典框架，但把每层的“人工设计优化过程”换成 CNN。

所以它不是完全黑盒的 CNN，而是很强地继承了传统 optical flow 的结构先验。

这也是论文中强调的点：SPyNet 把 classical spatial-pyramid formulation 和 deep learning 结合起来，而不是完全抛弃传统光流思想。

## 10. SPyNet 和 FlowNet 的区别
对比	FlowNet	SPyNet
思路	大 CNN 直接预测光流	金字塔逐层预测残差光流
大运动处理	主要靠网络学习	交给图像金字塔
每层任务	直接估计完整运动	估计小残差
参数量	较大	论文称比 FlowNet 小约 96%
可解释性	更黑盒	更接近传统光流 coarse-to-fine
工程用途	早期深度光流代表	视频复原里常用轻量光流模块

SPyNet 的优势是轻量、结构清晰、容易嵌入视频复原网络。缺点是它的光流精度和鲁棒性不如后来的一些强模型，比如 PWC-Net、RAFT 等。

## 11. SPyNet 在 BasicVSR / BasicVSR++ 里怎么用

你前面问的 BasicVSR、BasicVSR++、RealBasicVSR 都经常会涉及 SPyNet。

在这些视频超分模型中，SPyNet 通常不是最终输出结果的主干，而是一个 运动估计模块。

它负责估计相邻帧之间的光流，例如：

flow_{t→t-1}
flow_{t→t+1}

然后主网络用这些光流做 feature warping：

上一帧传播特征
    ↓ 光流 warp
对齐到当前帧
    ↓
和当前帧特征融合

MMagic 的 BasicVSR++ 实现中也有 compute_flow 逻辑，说明 SPyNet 用于 feature alignment，并返回 forward-time propagation 和 backward-time propagation 所需的光流。

注意这里的重点是：

SPyNet 估计的是运动场，真正做超分的是后面的 VSR 网络。

也就是说，SPyNet 是辅助对齐工具，不是视频超分模型本身。

## 12. 为什么视频超分里常用 SPyNet，而不是最新最强光流模型

原因很现实。

视频超分模型需要对很多帧反复估计光流。如果光流模型太大，会严重拖慢训练和推理。

SPyNet 的优点是：

轻量
速度相对快
容易集成
显存压力小
精度够用

虽然 RAFT 这类光流模型更强，但它更重。对于 BasicVSR 这类视频超分网络来说，光流只是对齐的第一步，后面的残差块、传播模块、可变形对齐模块还可以继续修正。因此不一定非要用最重的光流模型。

这也是为什么很多视频复原框架倾向用 SPyNet 作为 practical flow estimator。

## 13. 光流方向怎么理解

这个地方很容易搞混。

假设你当前要恢复第 t 帧，需要把第 t-1 帧的特征对齐到第 t 帧。

你需要的是：

当前帧 t 中每个位置，应该去 t-1 帧哪里取特征

也就是从当前帧坐标到前一帧坐标的采样关系。很多实现里叫：

flow_{t→t-1}

然后做：

aligned_feature_t = warp(feature_{t-1}, flow_{t→t-1})

为什么不是 flow_{t-1→t}？

因为 grid_sample / backward warping 通常是：对输出图像中的每个位置，去输入图像中采样对应点。所以你要输出当前帧坐标系下的特征，就需要知道当前帧每个位置在上一帧对应哪里。

这也是很多工程里最容易出 bug 的地方：

光流方向反了 → 对齐错位
坐标归一化错了 → warp 结果变形
flow 上采样忘记乘倍率 → 运动幅度错误

## 14. SPyNet 的训练方式

SPyNet 是有监督训练的光流网络。原论文使用 Flying Chairs 等合成光流数据训练，并在 Sintel、KITTI 等数据集上测试和微调。论文摘要也提到，SPyNet 在多个标准 benchmark 上与 FlowNet 比较，并且在一些数据集上优于 FlowNet。

为什么需要合成数据？

因为真实视频中很难获得每个像素的真实光流标注。Flying Chairs、FlyingThings、Sintel 这类数据可以提供 ground-truth flow。

训练目标一般是让预测光流接近真实光流：

L = |F_pred - F_gt|

常见指标是 EPE，也就是 endpoint error：

EPE = sqrt((u_pred - u_gt)^2 + (v_pred - v_gt)^2)

EPE 越低，光流越准。

## 15. SPyNet 的优点
15.1 轻量

这是 SPyNet 最突出的优点。原论文明确强调它比 FlowNet 参数量小约 96%，所以速度和内存占用更适合工程应用。

15.2 结构可解释

它不是纯黑盒，而是：

金字塔
warp
残差修正
逐层细化

每一步都很容易理解。

15.3 适合嵌入视频复原网络

视频超分里，光流模块通常只是辅助模块。SPyNet 轻量、够用，因此很适合作为 BasicVSR / BasicVSR++ / RealBasicVSR 这类模型的光流估计器。

15.4 对大运动有一定处理能力

通过低分辨率金字塔，大运动会变成小运动，逐层修正。

## 16. SPyNet 的局限
16.1 对复杂遮挡不够强

光流本质上假设两帧之间存在对应关系。但遮挡区域没有真实对应点。比如一个区域在当前帧出现，但上一帧被挡住了，那么光流很难准确估计。

16.2 对极端大运动和快速运动仍然困难

虽然金字塔可以处理大运动，但如果运动太大、模糊太严重、纹理太少，低分辨率也可能匹配错误。

16.3 细节边界可能不够准

SPyNet 比较轻量，边界处的光流精度不一定足够高。视频超分中如果直接用它 warp 特征，可能造成边缘模糊或重影。

这也是 BasicVSR++ 为什么要提出 flow-guided deformable alignment：光流提供大致方向，可变形对齐再做局部修正。

16.4 光流误差会传递到下游任务

如果 SPyNet 估计错了，后面的特征对齐就可能错。虽然 VSR 主干可以修正一部分，但光流方向严重错误时，输出还是容易出现伪影。

## 17. SPyNet 和 PWC-Net、RAFT 的区别
方法	核心思想	特点
SPyNet	图像金字塔 + CNN 残差光流	轻量，适合嵌入 VSR
PWC-Net	Pyramid + Warping + Cost Volume	精度更强，仍较高效
RAFT	全对相关性 + recurrent update	精度很强，但更重
FlowNet	端到端 CNN 直接预测	早期代表，参数较大

SPyNet 的定位不是“当前最强光流”，而是“轻量、结构清晰、够用”。在视频复原中，它的价值主要是提供一个便宜的运动先验。

## 18. 在代码里 SPyNet 通常怎么用
伪代码可以这样写：
```python
# 输入两帧
ref = frame_t        # 当前帧
supp = frame_t_minus_1  # 邻近帧

# 估计从当前帧到邻近帧的光流
flow = spynet(ref, supp)

# 用 flow 把邻近帧特征 warp 到当前帧
aligned_feat = flow_warp(feat_t_minus_1, flow)

# 后续融合
out_feat = fusion(current_feat, aligned_feat)
视频超分中的重点不是 flow 本身，而是：
flow → warp → aligned feature → temporal fusion
```
## 19. 常见工程坑
19.1 flow 方向弄反
这是最常见的错误。你要确认自己的 warp 是 backward warping 还是 forward warping。大多数 PyTorch grid_sample 实现是 backward warping。
19.2 flow 上采样忘记乘尺度
如果光流从低分辨率上采样到高分辨率，不能只插值，还要乘位移倍率：
flow_up = interpolate(flow) × scale
否则位移幅度会不对。
19.3 图像归一化不一致
SPyNet 训练时通常有自己的均值、方差归一化方式。如果推理时输入范围不对，比如该用 [0,1] 却用了 [0,255]，光流会明显错误。
19.4 padding 和尺寸问题
很多 SPyNet 实现要求输入尺寸能被 32 或 64 整除，因为要构建多层 pyramid。工程里常常需要先 pad 到合适尺寸，算完 flow 后再 crop 回来。
19.5 warp 坐标归一化
PyTorch grid_sample 使用的是归一化坐标 [-1, 1]。如果你直接把像素单位 flow 加到 grid 上，需要先做坐标尺度转换。

## 20. 面试里怎么讲 SPyNet

SPyNet 是一个轻量级光流估计网络，全名是 Spatial Pyramid Network。它把传统光流中的 coarse-to-fine 金字塔思想和深度学习结合起来。具体来说，它先构建两帧图像的多尺度金字塔，从最低分辨率开始初始化光流，然后逐层上采样到更高分辨率。在每个尺度上，SPyNet 会用当前光流把第二帧 warp 到第一帧坐标系下，再把第一帧、warp 后的第二帧和当前光流拼接起来，输入一个小 CNN，预测残差光流，最后用当前光流加残差光流得到更精细的估计。这样大运动由金字塔处理，每一层网络只需要估计小的残余运动，所以模型非常轻量。视频超分里，SPyNet 常作为运动估计模块，用来估计相邻帧之间的光流，再通过 feature warping 把邻近帧特征对齐到当前帧。它的优点是轻量、结构清晰、容易集成；缺点是复杂遮挡、大运动和边界区域的光流可能不够准，所以 BasicVSR++ 这类方法会在光流基础上再加入可变形对齐进行修正。

最核心的一句话：

SPyNet 的本质是：用图像金字塔把大运动拆成多个小运动，在每个尺度用小 CNN 预测残差光流，逐层 warp 和 refine，最终得到完整光流。
