# STFAN

STFAN 全名是 Spatio-Temporal Filter Adaptive Network for Video Deblurring，中文可以理解成 时空滤波自适应视频去模糊网络。它是 ICCV 2019 的视频去模糊方法，核心目标是：不用单独估计光流，而是用网络动态生成自适应滤波器，把“帧间对齐”和“当前帧去模糊”放到同一个框架里完成。 论文明确指出，传统方法通常先估计光流来对齐连续帧，但模糊视频中的光流很难估准，错误光流会带来伪影；STFAN 因此提出了统一的 spatio-temporal filter adaptive framework。

## 1. STFAN 解决的是什么问题

视频去模糊的输入是一段模糊视频：

B1, B2, B3, ..., Bt

输出是一段清晰视频：

S1, S2, S3, ..., St

相比单张图像去模糊，视频去模糊可以利用前后帧信息。比如当前帧中某个物体因为运动模糊看不清，但上一帧恢复后的结果可能已经包含比较清晰的结构信息。问题是：前后帧之间有运动，不能直接把上一帧特征拿来用。

传统视频去模糊常见流程是：

估计光流
    ↓
根据光流对齐前后帧
    ↓
多帧融合
    ↓
去模糊重建

但是模糊视频里，光流估计本身就很困难。强运动模糊、遮挡、低纹理区域都会导致光流不准。STFAN 的论文认为，单独估计 optical flow 再做对齐容易引入错误，因此它尝试把 alignment 对齐 和 deblurring 去模糊 都建模成 spatially adaptive filtering 空间自适应滤波 问题。

一句话：

STFAN 的核心不是“先光流对齐再去模糊”，而是“动态生成滤波器，同时完成时序对齐和空间去模糊”。

## 2. STFAN 的整体输入输出

STFAN 处理第 t 帧时，输入包括三个东西：

1. 上一帧模糊图像：B_{t-1}
2. 上一帧已经恢复的清晰图像：S_{t-1}
3. 当前帧模糊图像：B_t

输出是：

当前帧恢复结果：S_t

论文摘要和项目页都说明，STFAN takes both blurry and restored images of the previous frame as well as blurry image of the current frame as input，然后动态生成空间自适应滤波器用于 alignment 和 deblurring。

这点很重要。STFAN 不是一次输入一大段视频，也不是只输入当前帧，而是采用类似 recurrent 的形式：

上一帧恢复结果 + 上一帧模糊图 + 当前帧模糊图
        ↓
恢复当前帧
        ↓
当前恢复结果继续传给下一帧

所以它有一定的时序传播思想。

## 3. 为什么 STFAN 要输入上一帧恢复图

这个设计非常关键。

如果只输入上一帧模糊图 B_{t-1}，那么上一帧本身还是模糊的，能提供的清晰结构有限。

但 STFAN 输入的是：

B_{t-1} + S_{t-1} + B_t

其中 S_{t-1} 是上一时刻已经恢复出来的清晰结果。它可能包含比 B_{t-1} 更清楚的边缘和纹理，因此可以作为当前帧的参考。

直观理解：

上一帧恢复结果 S_{t-1}
    ↓
提供较清晰的历史信息

当前模糊帧 B_t
    ↓
提供当前帧真实内容和位置

网络动态生成滤波器
    ↓
把历史清晰信息对齐到当前帧，并去除当前帧模糊

这和 BasicVSR 这类 recurrent 视频超分类似：历史恢复/隐藏信息会沿时间传递。但 STFAN 不是用 hidden feature 加光流，而是用 上一帧恢复图像 + 自适应滤波器。

## 4. STFAN 的核心模块：FAC Layer

STFAN 最核心的模块叫：

Filter Adaptive Convolutional Layer，FAC Layer

中文可以叫 滤波自适应卷积层。

它的作用是：

根据输入图像内容，为每个空间位置动态生成不同的卷积滤波器。

普通卷积是这样的：

整张图共享同一组卷积核

例如一个 3×3 卷积核，在图像所有位置都一样：

位置 A 用这个卷积核
位置 B 也用这个卷积核
位置 C 还是用这个卷积核

但视频去模糊不是空间均匀问题。不同位置的模糊程度和运动方向可能完全不同：

背景区域：几乎不模糊
手部区域：快速运动，很模糊
边缘区域：方向性拖影
前景区域：和背景运动不同

所以固定卷积核不够。FAC Layer 的做法是：

不同空间位置生成不同滤波器

也就是：

位置 A：生成适合 A 的滤波器
位置 B：生成适合 B 的滤波器
位置 C：生成适合 C 的滤波器

论文中明确提出 FAC layer，用来对上一帧 deblurred features 做 alignment，同时对当前帧 features 去除 spatially variant blur。

## 5. FAC 为什么能同时做“对齐”和“去模糊”

这是 STFAN 最重要的思想。

论文认为：

帧间对齐 alignment 是空间变化的滤波问题
当前帧去模糊 deblurring 也是空间变化的滤波问题
5.1 对齐可以看成滤波

假设上一帧恢复图 S_{t-1} 中一个物体在左边，当前帧 B_t 中这个物体移动到了右边。传统方法会估计光流，然后把上一帧 warp 到当前帧。

STFAN 的理解是：

如果一个动态滤波器能在当前帧某个位置，从上一帧附近合适的位置采样并加权，就可以完成类似对齐的效果。

也就是说，滤波器的采样和加权可以隐式实现运动补偿。

5.2 去模糊也可以看成滤波

运动模糊本质上可以近似看成清晰图像被某个模糊核卷积：

模糊图像 = 清晰图像 * 模糊核

去模糊就是反过来恢复清晰图像。由于真实视频里的模糊核是空间变化的，所以需要每个位置都有不同的恢复滤波器。

因此，STFAN 用 FAC Layer 做两件事：

对上一帧恢复特征：
    用自适应滤波器做 alignment

对当前帧模糊特征：
    用自适应滤波器做 deblurring

这就是它所谓的 unified framework：对齐和去模糊都由动态滤波器完成。 论文和官方项目页都明确说，FAC layer 用于 align previous deblurred features and remove spatially variant blur from current features。

## 6. STFAN 的整体结构

STFAN 可以拆成三个部分：

1. Spatio-Temporal Filter Adaptive Network
   负责生成自适应滤波器

2. Feature Extraction Network
   负责提取上一帧和当前帧的特征

3. Reconstruction Network
   负责融合变换后的特征并重建清晰帧

论文补充材料中也说明，网络由 spatio-temporal filter adaptive network、feature extraction network 和 reconstruction network 三个子网络组成。

整体流程可以写成：

输入：
B_{t-1}, S_{t-1}, B_t

        ↓

STFAN 子网络：
根据输入动态生成两类滤波器

        ↓

Feature Extraction：
提取上一帧恢复图特征和当前模糊帧特征

        ↓

FAC Layer：
1. 对上一帧恢复特征做对齐
2. 对当前帧模糊特征做去模糊变换

        ↓

Feature Fusion：
融合两路变换后的特征

        ↓

Reconstruction：
输出当前清晰帧 S_t

简化图：

B_{t-1}, S_{t-1}, B_t
        ↓
动态生成 filter
        ↓
上一帧恢复特征 → FAC alignment
当前帧模糊特征 → FAC deblurring
        ↓
特征融合
        ↓
重建 S_t

7. 两类 FAC：时序对齐滤波器和空间去模糊滤波器

STFAN 里可以理解成有两类自适应滤波器：

7.1 Temporal filter：用于对齐历史帧信息

输入上一帧恢复结果 S_{t-1} 的特征，通过 FAC 变换后，得到和当前帧对齐的历史特征。

作用是：

把上一帧清晰信息迁移到当前帧坐标系

它解决的是 temporal alignment。

7.2 Spatial filter：用于当前帧去模糊

输入当前模糊帧 B_t 的特征，通过 FAC 变换后，去除当前帧中的空间变化模糊。

作用是：

根据当前帧不同位置的模糊程度，自适应恢复局部清晰结构

它解决的是 spatial deblurring。

这就是名字里 Spatio-Temporal 的含义：

Spatial：当前帧内部的空间变化模糊
Temporal：前后帧之间的运动对齐

## 8. STFAN 和光流对齐方法的区别

传统视频去模糊常用光流：

估计 flow
    ↓
warp 上一帧/邻近帧
    ↓
融合

STFAN 不显式估计光流，而是：

生成自适应滤波器
    ↓
隐式完成对齐
对比	光流方法	STFAN
对齐方式	显式 optical flow + warp	FAC 动态滤波隐式对齐
对模糊视频	光流可能估不准	不依赖单独光流估计
模块关系	对齐和去模糊分开	对齐和去模糊统一
复杂运动	光流错误会引入伪影	动态滤波可局部自适应
可解释性	光流直观	滤波器直观，但运动不显式

STFAN 的优势是避免了“先估计错误光流，再基于错误光流恢复”的问题。论文明确把 separate optical flow estimation 的局限作为提出 STFAN 的动机。

## 9. STFAN 和普通动态卷积的关系

STFAN 的 FAC Layer 可以看成一种动态卷积，但它比普通动态卷积更任务化。

普通动态卷积通常是：

根据输入生成卷积核
    ↓
用这个卷积核处理当前特征

STFAN 的动态卷积有明确任务：

一类 filter 用来对齐历史恢复特征
一类 filter 用来去除当前帧空间变化模糊

所以它不是单纯“让卷积核变动态”，而是把视频去模糊中的两个核心问题都抽象成动态滤波。

这点很适合面试讲：

STFAN 的创新点不只是用了动态卷积，而是把 alignment 和 deblurring 统一为 filter adaptive convolution，使一个网络可以根据时空上下文动态生成位置相关的滤波器。

## 10. STFAN 的递推过程

假设输入视频是：

B1, B2, B3, B4, ...

STFAN 的推理可以这样理解。

第 1 帧没有上一帧恢复结果，可以用当前帧初始化或单帧处理：

B1 → S1

第 2 帧：

输入：B1, S1, B2
输出：S2

第 3 帧：

输入：B2, S2, B3
输出：S3

第 4 帧：

输入：B3, S3, B4
输出：S4

也就是：

S_{t-1} 参与恢复 S_t
S_t 又继续参与恢复 S_{t+1}

这种结构有一个优点：

上一帧已经恢复出的清晰信息可以沿时间传播，帮助后续帧恢复。

但也有一个风险：

如果某一帧恢复错了，错误可能传播到后续帧。

这是所有 recurrent 视频复原方法都需要注意的问题。

## 11. STFAN 为什么适合视频去模糊

STFAN 适合视频去模糊，主要因为它同时考虑了两个因素：

11.1 利用历史清晰信息

上一帧恢复结果 S_{t-1} 可能比当前模糊帧更清晰。通过 temporal FAC 对齐后，可以为当前帧提供参考。

11.2 处理空间变化模糊

视频模糊通常不是全图一个固定模糊核，而是不同位置模糊方向和程度不同。Spatial FAC 可以为不同位置生成不同滤波器，更适合 non-uniform blur。

11.3 不强依赖光流

模糊视频里光流很难估准。STFAN 避免单独光流估计，用滤波器隐式处理运动和模糊，减少错误光流造成的伪影风险。

论文在 benchmark 和真实视频上都报告 STFAN 相比当时方法在准确率、速度和模型大小方面具有竞争力。

## 12. STFAN 和 EDVR 的区别

EDVR 和 STFAN 都是经典视频复原方法，但思路不同。

对比	STFAN	EDVR
任务重点	视频去模糊	视频超分/去模糊/复原
时间结构	recurrent，使用上一帧恢复结果	滑动窗口，多帧输入中心帧
对齐方式	FAC 动态滤波隐式对齐	PCD 可变形卷积对齐
融合方式	对齐特征 + 当前去模糊特征融合	TSA 时空注意力融合
光流依赖	不显式估计光流	不显式用光流，主要靠 DCN
优点	对齐和去模糊统一，结构思想清楚	多帧窗口内对齐融合能力强
缺点	历史错误可能递推传播	滑窗重复计算，DCN 部署复杂

一句话：

STFAN 强调“用动态滤波统一对齐和去模糊”，EDVR 强调“用 PCD 对齐多帧，用 TSA 融合多帧”。

## 13. STFAN 和 ESTRNN 的区别

ESTRNN 是高效 RNN 视频去模糊模型，STFAN 也是时序递推模型，但重点不同。

对比	STFAN	ESTRNN
核心模块	FAC Layer	RDB-based RNN Cell + GSA
历史信息	上一帧恢复图像	hidden state / 层级特征
对齐方式	动态滤波隐式对齐	主要靠 RNN 特征传播和 GSA 筛选
去模糊方式	spatial adaptive filter	RDB 空间特征提取 + 重建
是否用未来帧	主要使用上一帧	可使用前后多帧特征
工程定位	统一滤波思想清晰	更偏高效 RNN 视频去模糊

一句话：

STFAN 更像“基于动态滤波的递推视频去模糊”，ESTRNN 更像“基于 RNN hidden state 和注意力的高效视频去模糊”。

## 14. STFAN 和 CDVD-TSP 的区别

CDVD-TSP 强调 temporal sharpness prior，也就是利用视频中相对清晰的帧作为参考，并通过级联方式逐步恢复。

对比	STFAN	CDVD-TSP
核心思想	对齐和去模糊统一为动态滤波	利用时间锐度先验和级联恢复
是否估计光流	不显式估计光流	会涉及潜在清晰帧和光流估计
结构风格	recurrent	cascaded
优点	避免单独光流错误	对存在清晰参考帧的视频有效
缺点	历史错误传播	流程更复杂

## 15. STFAN 和 RVRT / VRT 的区别

VRT 和 RVRT 是后来的 Transformer 视频复原模型，表达能力更强，但也更重。

对比	STFAN	VRT / RVRT
年代	ICCV 2019	2022 之后
主体	CNN + dynamic filtering	Transformer + attention
对齐	FAC 动态滤波	mutual attention / GDA / warping
时序建模	上一帧递推	clip-level / long-range modeling
计算复杂度	相对轻	更高
工程定位	经典视频去模糊方法	高质量视频复原

如果你追求最新高质量离线效果，RVRT / VRT 更强；如果你想讲视频去模糊里“动态滤波统一对齐和去模糊”的思想，STFAN 很经典。

## 16. STFAN 的优点

第一，避免显式光流估计。
模糊视频中的光流估计很难，STFAN 不单独估计 optical flow，而是用 FAC 动态滤波完成隐式对齐。

第二，对齐和去模糊统一。
STFAN 把 temporal alignment 和 spatial deblurring 都看成空间自适应滤波问题，用同一类 FAC 机制处理。

第三，能利用上一帧恢复结果。
上一帧恢复图提供了较清晰的历史信息，经过自适应滤波对齐后可以辅助当前帧恢复。

第四，适合空间变化模糊。
动态生成位置相关滤波器，比固定卷积更适合处理不同区域模糊程度不同的问题。

第五，思想清晰，适合面试讲解。
它的创新点非常明确：不用光流，用 filter adaptive convolution 把对齐和去模糊统一起来。

## 17. STFAN 的局限

第一，长时序建模有限。
STFAN 主要利用上一帧恢复结果，不像 BasicVSR++、RVRT 那样利用长时间范围的传播或 clip-level attention。

第二，错误可能递推传播。
由于 S_{t-1} 会参与恢复 S_t，如果上一帧恢复出现伪影，可能影响当前帧。

第三，对复杂大运动和遮挡仍有挑战。
FAC 可以隐式对齐，但没有显式长距离匹配能力。极端大运动、遮挡、快速变形场景下，可能不如更强的 attention / deformable alignment 模型。

第四，现在工程热度不如后来的 RVRT / EDVR / ESTRNN。
STFAN 是经典方法，但如果做当前高质量离线视频去模糊，很多人会优先尝试 RVRT、VRT、EDVR 或更现代的视频复原模型。

## 18. 工程上怎么用 STFAN

一个典型推理流程是：

输入模糊视频
    ↓
读取第 1 帧，初始化恢复结果 S1
    ↓
对第 t 帧：
    输入 B_{t-1}, S_{t-1}, B_t
    生成自适应滤波器
    对齐上一帧恢复特征
    去模糊当前帧特征
    融合并重建 S_t
    ↓
保存 S_t，并传给下一帧
    ↓
合成输出视频

工程注意点：

1. 第一帧如何初始化很重要
2. 长视频中错误递推要注意
3. 视频镜头切换处不能直接使用上一帧恢复结果
4. 可加入 scene cut 检测，镜头切换时重置历史信息
5. 如果输入视频同时有噪声/压缩伪影，最好先做轻量去噪或联合训练

尤其是镜头切换：

上一帧是 A 场景
当前帧是 B 场景

如果继续用 S_{t-1} 参与恢复 B_t，会引入错误历史信息。因此实际视频处理时，最好做 scene cut 检测。

## 19. 面试里怎么讲 STFAN


STFAN 是一个经典的视频去模糊模型，全名是 Spatio-Temporal Filter Adaptive Network。它主要解决传统视频去模糊中依赖光流对齐的问题。由于模糊视频里光流很难估准，错误光流会导致重影和伪影，所以 STFAN 不单独估计光流，而是把帧间对齐和当前帧去模糊统一看成空间自适应滤波问题。具体来说，模型输入上一帧模糊图、上一帧已经恢复的清晰图和当前模糊图，然后通过 spatio-temporal filter adaptive network 动态生成滤波器。FAC Layer 会用一类滤波器对上一帧恢复特征进行时序对齐，用另一类滤波器对当前帧特征进行空间去模糊，最后融合两路变换后的特征并重建当前清晰帧。它的优点是避免了显式光流估计，把 alignment 和 deblurring 放进统一框架，适合处理空间变化模糊；缺点是主要依赖上一帧恢复结果，长时序建模有限，错误可能递推传播，复杂大运动和遮挡场景下不如后来的 EDVR、RVRT、VRT 这类更强模型。

最后记住一句话：

STFAN 的本质是：用动态生成的空间自适应滤波器，把上一帧恢复结果对齐到当前帧，同时去除当前帧的空间变化模糊，从而避免显式光流估计带来的误差。
