# 视频增强

视频增强 = 单帧图像恢复能力 + 多帧时序信息利用能力 + 运动对齐能力 + 时序一致性控制能力。

要重点掌握这几类任务：

1. 视频超分辨率 Video Super-Resolution, VSR
2. 视频去噪 Video Denoising
3. 视频去模糊 Video Deblurring
4. 压缩视频增强 Compressed Video Enhancement
5. 低照度视频增强 Low-light Video Enhancement
6. 视频插帧 Video Frame Interpolation

## 一、视频增强和图像增强最大的区别

图像增强只处理单张图：

输入：一张低质量图像
输出：一张高质量图像

视频增强处理的是连续帧：

输入：多帧低质量视频帧
输出：多帧高质量视频帧

视频任务比图像任务多了一个核心问题：

相邻帧之间有运动，同一个物体在不同帧的位置不一样。

所以视频增强不是简单把每一帧丢进图像增强模型，而是要利用：

前后帧互补信息
时序连续性
运动对齐
长程传播
跨帧融合

例如视频超分中，某一帧模糊或细节缺失，前后帧可能刚好有清晰纹理；模型要把这些信息对齐后融合。BasicVSR++ 论文也把 VSR 的挑战概括为需要从相互错位的视频帧中收集互补信息，并提出增强传播和对齐来更有效利用时空信息。

## 二、必须掌握的核心概念
### 1. 退化模型 Degradation

视频增强首先要知道低质量视频是怎么来的。

常见退化包括：

低分辨率：downsample
噪声：Gaussian noise / Poisson noise / sensor noise
模糊：motion blur / defocus blur
压缩伪影：H.264 / H.265 / JPEG artifact
低照度：under-exposure, low SNR
混合退化：blur + noise + compression + low resolution

训练时经常用人工退化构造数据：

高质量视频
↓
下采样
↓
加噪声
↓
加模糊
↓
加压缩
↓
得到低质量视频

真实场景更复杂，因为真实视频往往是多种退化叠加的，这也是 RealBasicVSR 这类真实视频超分方法关注的问题。RealBasicVSR 论文指出，真实世界视频退化具有多样性和复杂性，严重退化会在传播过程中被放大，因此引入了 image pre-cleaning 阶段来先抑制噪声和伪影。

### 2. 时序信息 Temporal Information

视频增强的优势来自多帧信息。

例如：

当前帧看不清的纹理
可能在前一帧或后一帧更清楚

所以模型要利用：

t-2, t-1, t, t+1, t+2

这样的邻近帧。

常见输入形式：

滑动窗口：连续 5 帧 / 7 帧 / 15 帧
递归传播：从过去帧持续传播隐藏特征
双向传播：同时利用过去和未来帧
长程建模：Transformer 或 recurrent 结构建模更长时序
### 3. 运动对齐 Motion Alignment

因为视频中物体会运动，所以不能直接把前后帧相加。

要先对齐：

前一帧的物体位置
↓
对齐到当前帧
↓
再融合

常见对齐方法有：

光流 Optical Flow
可变形卷积 Deformable Convolution
特征级对齐 Feature Alignment
注意力对齐 Attention Alignment
隐式对齐 Implicit Alignment

EDVR 的核心就是 PCD alignment，即 Pyramid, Cascading and Deformable alignment，用可变形卷积在特征层做 coarse-to-fine 对齐；同时还用 TSA fusion 做时空注意力融合。

### 4. 特征传播 Feature Propagation

视频模型通常不是只看固定窗口，还会把信息沿时间传播。

例如 BasicVSR 的思路：

前向传播：从第 1 帧传到第 T 帧
后向传播：从第 T 帧传回第 1 帧
融合双向特征
重建高质量帧

BasicVSR++ 在这个基础上进一步提出：

second-order grid propagation
flow-guided deformable alignment

用更强的传播和对齐机制提升时空信息利用

## 三、视频超分辨率 VSR 需要掌握什么？
### 1. VSR 任务定义

视频超分辨率是：

输入：低分辨率视频帧 LR
输出：高分辨率视频帧 HR

常见倍率：

×2
×3
×4

数学上可以理解为：

给定 LR_{t-k}, ..., LR_t, ..., LR_{t+k}
预测 HR_t

或者预测整个 HR 序列。

### 2. VSR 的核心难点


3. 多帧之间存在运动，需要对齐
4. 低分辨率帧本身细节缺失，需要从多帧中补充
5. 对齐不准会产生重影 ghosting
6. 过强生成会产生假纹理 hallucination
7. 相邻输出帧要时序稳定，不能闪烁 flickering
8. 真实视频中常有噪声、压缩、模糊混合退化

### 3. VSR 模型路线
传统单帧路线

只把每一帧当作图片做超分：

LR_t
↓
Image SR model
↓
HR_t

优点：

简单
不会引入跨帧对齐错误

缺点：

没有利用时序信息
细节恢复有限
输出容易缺少时间一致性
多帧滑动窗口路线

输入连续几帧：

LR_{t-2}, LR_{t-1}, LR_t, LR_{t+1}, LR_{t+2}
↓
对齐
↓
融合
↓
重建 HR_t

代表思想：

EDVR

EDVR 是很经典的视频恢复框架，可以用于视频超分和去模糊，其核心是 PCD 对齐和 TSA 融合。

递归传播路线

不是只看固定窗口，而是沿时间传播特征：

frame 1 → frame 2 → frame 3 → ... → frame T

代表模型：

BasicVSR
BasicVSR++
RealBasicVSR

BasicVSR 使用双向传播和特征对齐来利用整个视频序列信息；BasicVSR++ 进一步通过二阶网格传播和 flow-guided deformable alignment 提升效果。

Transformer 路线

Transformer 用注意力机制建模长程时序关系。

代表模型：

VRT
RVRT
Video SwinIR 类方法

VRT 提出 Video Restoration Transformer，使用 temporal mutual self-attention 和 parallel warping 来建模长程时序依赖，并在视频超分、视频去模糊、视频去噪、视频插帧等多个任务上验证效果。

RVRT 则尝试结合 recurrent 和 transformer 的优点，把视频划分成多个 clip，在全局递归框架内并行处理局部邻近帧，以平衡效果和效率。

4. VSR 面试必须会讲的模型

你至少要会讲这几个：

EDVR
BasicVSR
BasicVSR++
RealBasicVSR
VRT / RVRT

面试回答可以这样组织：

视频超分的关键是跨帧信息利用。早期方法常用滑动窗口结构，例如 EDVR，它通过 PCD 可变形卷积对齐多帧特征，再用 TSA 注意力融合；后来的 BasicVSR 采用双向递归传播，把整个视频序列的信息前后传播；BasicVSR++ 在此基础上增强传播和对齐，提出二阶网格传播和 flow-guided deformable alignment；对于真实视频退化，RealBasicVSR 在传播前加入清理模块，防止噪声和压缩伪影在时序传播中被放大；Transformer 类方法如 VRT/RVRT 则通过时序注意力建模更长程依赖。

## 四、视频去噪需要掌握什么？
### 1. 视频去噪任务定义

视频去噪是：

输入：带噪声视频
输出：干净视频

常见噪声：

Gaussian noise
Poisson noise
shot noise
read noise
low-light noise
compression noise
real sensor noise
### 2. 视频去噪和图像去噪的区别

图像去噪只看一张图。

视频去噪可以利用多帧：

同一个物体在多帧中都有出现
噪声通常是随机的
真实结构在时间上更稳定

所以多帧平均理论上可以降低噪声。

但是问题是：

物体运动会导致不对齐
直接平均会产生拖影

所以视频去噪也需要：

运动补偿
多帧融合
时序一致性控制
### 3. 视频去噪常见方法
传统方法
V-BM4D
Non-local means
Patch matching
Temporal averaging

传统方法强调 patch 相似性和时空非局部匹配。

深度学习方法

代表模型：

DVDnet
FastDVDnet
RViDeNet
VRT/RVRT denoising

FastDVDnet 是一个经典实时深度视频去噪方法，它不依赖显式光流估计，强调较低计算量和较快推理速度，并且能用单个模型处理较宽范围噪声水平。

### 4. 视频去噪面试重点

1. 为什么视频去噪可以利用多帧？
2. 为什么直接多帧平均不行？
3. 运动补偿在去噪中有什么作用？
4. 噪声模型有哪些？
5. 合成噪声和真实噪声有什么区别？
6. 为什么低照度视频去噪更难？
7. 怎么评估去噪效果？

面试回答可以这样说：

视频去噪的关键是利用时域冗余。相邻帧中真实结构通常具有连续性，而噪声具有随机性，因此多帧信息可以帮助抑制噪声。但由于视频中存在相机运动和物体运动，直接平均会产生重影，所以需要对齐或隐式融合。传统方法依赖 patch matching，深度方法可以通过光流、可变形卷积、时序注意力或无光流结构进行多帧融合。FastDVDnet 这类方法不使用显式光流，而是通过网络结构学习多帧去噪，在速度和效果之间取得平衡。

## 五、视频去模糊需要掌握什么？
### 1. 视频模糊来源

常见视频模糊有：

相机抖动导致的运动模糊
物体快速运动导致的局部模糊
失焦模糊 defocus blur
低帧率导致的动态模糊
压缩和噪声叠加导致的退化
### 2. 视频去模糊任务定义
输入：模糊视频帧序列
输出：清晰视频帧序列

关键是：

利用前后帧互补清晰信息
恢复当前帧锐利边缘和纹理

例如当前帧某个区域很糊，前一帧或后一帧可能更清楚。

### 3. 视频去模糊难点
1. 模糊核空间变化，不是整张图一个固定 kernel
2. 相机运动和物体运动混合
3. 模糊区域和清晰区域同时存在
4. 对齐困难，模糊本身会影响光流估计
5. 过度锐化会产生 ringing artifact
6. 输出视频容易时序闪烁
4. 视频去模糊常见模型路线

常见方法包括：

多帧 CNN
光流对齐 + 融合
可变形卷积对齐
encoder-decoder / U-Net
recurrent restoration
Transformer restoration

EDVR 本身就是一个统一视频恢复框架，可用于视频超分和去模糊；其项目页也说明，对于 blurry inputs，会在 PCD 对齐模块前加入 PreDeblur 模块来提高对齐准确性。

VRT 也把视频去模糊作为其验证任务之一，并通过时序注意力和并行 warping 建模跨帧信息。

## 六、三个任务之间的共同核心

视频超分、去噪、去模糊虽然目标不同，但底层共性很强。

任务	主要退化	恢复目标	关键难点
视频超分	分辨率低、细节缺失	恢复高分辨率细节	多帧对齐、细节重建
视频去噪	随机噪声、传感器噪声	抑制噪声保留纹理	去噪不能抹掉细节
视频去模糊	运动模糊、失焦模糊	恢复清晰边缘	模糊下对齐困难
压缩增强	block artifact、ringing	去伪影、保细节	压缩伪影和纹理混淆

共同技术点：

1. 多帧输入
2. 运动估计 / 特征对齐
3. 跨帧融合
4. 时序传播
5. 残差学习
6. 多尺度重建
7. 时序一致性约束

## 八、评价指标必须掌握
### 1. PSNR
Peak Signal-to-Noise Ratio

衡量恢复图像和 GT 的像素误差。

特点：

越高越好
偏向像素级准确
和人眼感知不完全一致
### 2. SSIM
Structural Similarity Index

衡量结构相似度。

特点：

越高越好
比 PSNR 更关注结构
### 3. LPIPS

感知质量指标。

特点：

越低越好
更接近人眼感知
常用于生成式增强、真实视频超分
### 4. NIQE / BRISQUE

无参考图像质量指标。

适合没有 GT 的真实视频增强。

#### 5. Temporal Consistency

视频任务特别关注：

时序一致性
闪烁 flickering
运动区域稳定性

常见评估方式：

warp error
tOF
tLPIPS
人工主观评价
视频播放观察

视频增强不能只看单帧 PSNR，还要看连续帧是否稳定，有没有闪烁、重影和纹理跳变。

## 十一、必须会答的问题
### 1. 视频超分和图像超分有什么区别？

可以回答：

图像超分只利用单帧信息，而视频超分可以利用相邻帧的互补信息来恢复细节。但视频中存在运动，同一物体在不同帧的位置不一致，所以视频超分的关键是运动对齐和跨帧融合。如果对齐不准，可能产生重影和闪烁。因此 VSR 模型通常会使用光流、可变形卷积、时序注意力或递归传播来利用多帧信息。

### 2. 为什么视频增强需要运动对齐？

可以回答：

因为相邻帧之间存在相机运动和物体运动，直接融合不同帧特征会把不同位置的内容混在一起，产生 ghosting。运动对齐的作用是把前后帧中对应当前帧同一物体或区域的特征对齐后再融合。常用方法包括光流对齐、可变形卷积对齐和注意力对齐。

### 3. 光流对齐和可变形卷积对齐有什么区别？

可以回答：

光流对齐先估计像素级运动场，然后用 warping 把邻近帧对齐到当前帧，优点是运动含义明确，缺点是光流估计错误会直接影响恢复效果。可变形卷积对齐是在特征层学习采样偏移，不需要显式输出光流，能够更灵活地对齐复杂运动和局部形变。EDVR 的 PCD alignment 就是典型的多尺度可变形卷积特征对齐。

### 4. 视频增强为什么会出现闪烁？

可以回答：

闪烁通常来自相邻帧恢复结果不一致。比如模型逐帧处理时，每一帧的纹理生成、颜色校正或噪声残留都可能不同；或者跨帧对齐不稳定，导致细节在时间上跳动。解决方式包括使用多帧输入、递归传播、时序一致性 loss、光流约束、滑动窗口融合，以及推理阶段保持时序 hidden state 稳定。

### 5. 视频去噪为什么不能简单逐帧去噪？

可以回答：

逐帧去噪没有利用视频时序冗余，容易过度平滑细节，而且相邻帧去噪结果可能不一致，造成闪烁。视频去噪可以利用多帧中相同结构的重复出现来区分真实纹理和随机噪声，但需要处理帧间运动，否则直接融合会产生拖影。

### 6. 视频去模糊为什么比图像去模糊难？

可以回答：

视频去模糊不仅要恢复单帧清晰结构，还要利用前后帧互补信息并保证时序一致。模糊本身会破坏纹理和边缘，导致运动估计和对齐更困难；同时视频中不同区域可能有不同运动模糊，属于空间变化退化，不能简单用固定模糊核处理。

## 十四、最终总结

视频增强，必须掌握这条知识链：

视频退化类型
↓
多帧输入建模
↓
运动对齐
↓
时序特征传播
↓
跨帧融合
↓
重建输出
↓
时序一致性评估
↓
工程部署

最重要的模型主线是：

EDVR：
滑动窗口 + PCD 可变形卷积对齐 + TSA 融合

BasicVSR：
双向递归传播 + 光流对齐

BasicVSR++：
二阶网格传播 + flow-guided deformable alignment

RealBasicVSR：
真实退化 + pre-cleaning + 防止伪影传播

FastDVDnet：
无显式光流的快速视频去噪

VRT / RVRT：
Transformer 建模长程时序依赖

总结可以这样说：

视频增强的核心不是单帧恢复，而是如何稳定、有效地利用多帧时序信息。关键技术包括运动对齐、时序传播、跨帧融合和时序一致性控制；典型模型从 EDVR 的可变形卷积对齐，到 BasicVSR 系列的递归传播，再到 VRT/RVRT 的 Transformer 长程建模，都是围绕如何更好利用跨帧信息来提升超分、去噪和去模糊效果。

## 十五、目前工程上真正常用的视频超分

大致分成 逐帧图像超分、时序视频超分、轻量实时超分、商业 SDK / 闭源方案 四类。实际落地时，大家不一定用论文里最新最强的模型，而是优先考虑 速度、显存、稳定性、部署难度、是否闪烁、是否支持真实退化视频。

### 1. Real-ESRGAN 系列：工程落地最常见的一类

严格来说，Real-ESRGAN 更偏 图像超分 / 图像修复模型，用于视频时通常是把视频拆帧，对每一帧单独超分，再合成视频。它的优势是部署简单、效果直观、真实低清图像适应性比传统 ESRGAN 更好，所以在动漫修复、老视频修复、短视频增强、小工具软件里非常常见。官方也明确把 Real-ESRGAN 定位为 practical algorithms for general image/video restoration，并提供 general、anime、anime video 等模型。

工程上常见模型包括：

模型	常见用途	优点	缺点
RealESRGAN_x4plus	通用真实图像/视频帧超分	效果稳，部署资料多	逐帧处理，可能闪烁
RealESRGAN_x4plus_anime_6B	动漫图片/视频帧	小、快、适合二次元	不适合真实场景
realesr-animevideov3	动漫视频	专门优化动漫视频，模型小	仍然主要是逐帧增强
realesr-general-x4v3	通用轻量增强	更快，可调降噪强度	细节生成能力弱于大模型

如果你要快速做一个视频增强 Demo，Real-ESRGAN 是最容易落地的选择：ffmpeg 拆帧 → Real-ESRGAN 推理 → ffmpeg 合成。官方文档里也给了这种视频处理流程，并且有 ncnn-vulkan 版本，适合不依赖 PyTorch 的桌面端部署。

不过它最大的问题是：没有真正利用时间信息。如果每一帧生成的纹理略有不同，视频播放时可能出现闪烁、纹理跳动。

### 2. BasicVSR / IconVSR / BasicVSR++：视频超分工程和论文里最常见的主干

如果你问的是“真正的视频超分模型”，那 BasicVSR 系列一定要掌握。BasicVSR 的核心是 双向时序传播 + 光流特征对齐，让当前帧同时利用过去帧和未来帧信息；BasicVSR++ 进一步提出 二阶网格传播 和 光流引导可变形对齐，在类似参数量下比 BasicVSR 提升明显。MMagic 文档也说明 BasicVSR++ 相比 BasicVSR 提升约 0.82 dB PSNR。

模型	常见用途	优点	工程问题
BasicVSR	视频超分 baseline	结构清晰，适合面试讲解	依赖光流，复杂运动会出错
IconVSR	BasicVSR 增强版	加入信息补充和耦合传播	比 BasicVSR 更复杂
BasicVSR++	高质量视频超分	时序传播强，对齐更准	DCN / deformable conv 部署麻烦
Light-BasicVSR++	较轻量版本	性能和速度折中	效果不如完整模型

工程上如果是 服务器离线处理，BasicVSR++ 很有吸引力；如果是 实时端侧部署，BasicVSR++ 的可变形卷积、光流、显存占用都会增加难度。BasicVSR++ 官方项目也强调，它通过 second-order grid propagation 和 flow-guided deformable alignment 改进 BasicVSR。

你面试时可以这样说：

如果只是快速做视频增强工具，Real-ESRGAN 更容易落地；如果要体现“视频算法能力”，我会选择 BasicVSR 或 BasicVSR++，因为它们真正利用了多帧时序信息，能解决逐帧超分的闪烁问题。

### 3. RealBasicVSR：真实世界视频超分更常用

BasicVSR 和 BasicVSR++ 在标准数据集上很强，但真实视频里有压缩噪声、运动模糊、抖动、过曝、欠曝、码率损伤等问题。RealBasicVSR 就是面向 real-world video super-resolution 的方法。它关注真实退化视频中的一个关键问题：长时序传播虽然有利于轻度退化，但严重退化会在传播中被放大，影响输出质量。

工程上，RealBasicVSR 比 BasicVSR 更适合以下场景：

低码率视频增强；

老视频修复；

网络压缩视频增强；

监控视频清晰化；

真实手机拍摄视频增强。

它的定位可以理解为：

BasicVSR / BasicVSR++ 更偏标准 VSR benchmark；RealBasicVSR 更偏真实退化视频工程落地。

如果你要做一个“真实视频增强项目”，RealBasicVSR 比单纯 BasicVSR 更有说服力。

### 4. EDVR：老牌但仍常见的滑动窗口视频恢复模型

EDVR 是较早非常经典的视频恢复框架，核心是 PCD 对齐 + TSA 融合。PCD 是 pyramid cascading deformable alignment，用多尺度可变形卷积做特征对齐；TSA 是 temporal-spatial attention，用于时序和空间注意力融合。官方项目页把 EDVR 定位为统一的视频恢复框架，可用于超分、去模糊等任务。

EDVR 工程上的特点是：

项目	说明
框架类型	滑动窗口式视频超分
输入方式	当前帧附近若干帧
优点	结构成熟，资料多，效果稳
缺点	长时序利用不如 BasicVSR 系列
部署难点	deformable conv 需要额外算子支持

现在很多新项目未必首选 EDVR，但它仍然是视频恢复领域很重要的 baseline。你面试时知道 EDVR，会显得你不是只了解 BasicVSR。

### 5. VRT / RVRT：高质量离线视频修复，部署成本较高

VRT 和 RVRT 属于 Transformer 视频恢复模型。VRT 使用时空注意力建模多帧依赖，RVRT 则结合 recurrent 思路和 guided deformable attention，在视频超分、去模糊、去噪任务上都有很强表现。VRT 官方说明它面向 video restoration，例如 video super-resolution；RVRT 官方说明它在视频超分、去模糊、去噪上取得 SOTA，并强调模型大小、显存和速度之间的平衡。

这类模型适合：

离线高质量修复；

影视级增强；

论文实验；

服务器批处理。

但它们不太适合普通实时部署，因为 Transformer 视频模型通常显存压力大、推理慢、工程优化复杂。尤其是长视频，需要切块、分段、缓存和边界融合。

6. 轻量单帧超分模型：移动端、实时流媒体更常用

如果是手机端、嵌入式、实时视频流，不一定能跑 BasicVSR++ 或 RVRT。很多工程会退而求其次，用轻量图像超分模型逐帧处理，例如：

模型	特点
FSRCNN	很轻，速度快，适合实时
ESPCN	PixelShuffle 经典方法，轻量
LapSRN	逐级上采样
EDSR-lite	效果比 FSRCNN/ESPCN 强，但更重
IMDN / RFDN / RLFN	轻量图像超分常见选择
SwinIR-light	效果较好，但比纯 CNN 重

OpenCV 的 dnn_superres 模块就集成了 EDSR、ESPCN、FSRCNN、LapSRN 这几类模型，因此它们在工程快速验证和轻量部署里仍然常见。

这类方法的问题还是：逐帧处理，不保证时间一致性。但如果业务更关心实时速度，比如摄像头预览、低端设备视频增强，它们反而比大模型更现实。

7. NVIDIA Maxine / 商业 SDK：真正产品化时也很常见

在会议、直播、实时视频增强场景里，很多公司不会从论文模型开始自己训练，而是直接用商业 SDK 或闭源模型。例如 NVIDIA Maxine Video Effects SDK 提供 Video Super Resolution，官方说明它是 AI-powered upscaling，除了提升分辨率，还支持 denoise 和 deblur 模式，并面向实时视频增强。

这种方案的特点是：

优点	缺点
工程成熟、实时性好	模型细节不可控
和 NVIDIA GPU 生态结合好	依赖特定硬件和 SDK
适合会议、直播、视频处理软件	不适合作为论文创新点

如果你的目标是求职面试，可以知道这类方案，但项目里最好还是讲开源模型，比如 Real-ESRGAN、BasicVSR++、RealBasicVSR。

按场景推荐
场景	推荐模型
快速做视频增强 Demo	Real-ESRGAN / realesr-general-x4v3
动漫视频超分	realesr-animevideov3 / RealESRGAN anime
真实低清视频修复	RealBasicVSR / Real-ESRGAN
想体现视频时序建模能力	BasicVSR / BasicVSR++
追求高质量离线修复	BasicVSR++ / RVRT / VRT
老牌视频恢复 baseline	EDVR
移动端 / 实时低延迟	FSRCNN / ESPCN / RFDN / IMDN / EDSR-lite
商业实时视频增强	NVIDIA Maxine VSR
最实际的工程选择

如果你现在要做一个面试项目，我建议这样选：

第一版：Real-ESRGAN
最快落地，能做出明显前后对比，有视频输出，工程完整。

第二版：BasicVSR++ 或 RealBasicVSR
体现你理解视频超分中的多帧对齐、时序传播、光流、时间一致性。

第三版：部署优化
把模型转 ONNX / TensorRT / ncnn，加入视频拆帧、批处理、tile 推理、音视频合成、显存控制。

面试里你可以这样总结：

工程落地中，最常见的是 Real-ESRGAN 这类逐帧真实超分模型，因为部署简单、效果直观；如果要真正利用视频时序信息，常用 BasicVSR、BasicVSR++、RealBasicVSR、EDVR 这类视频恢复模型；如果追求离线高质量，可以考虑 VRT/RVRT；如果是移动端或实时业务，通常会选择 FSRCNN、ESPCN、RFDN、EDSR-lite 这类轻量模型，或者直接使用 NVIDIA Maxine 等商业 SDK。
