## 一、这个项目到底在做什么？

Spaceship Titanic 的目标是：

根据乘客的星球、舱位、是否冷冻睡眠、消费信息、年龄、目的地等特征，预测该乘客是否被 Transported。

数据里比较重要的字段有：

字段	含义
PassengerId	乘客 ID，例如 0001_01
HomePlanet	出发星球
CryoSleep	是否处于冷冻睡眠
Cabin	舱位，例如 B/0/P
Destination	目的地
Age	年龄
VIP	是否 VIP
RoomService	房间服务消费
FoodCourt	餐饮消费
ShoppingMall	商场消费
Spa	Spa 消费
VRDeck	VR 娱乐消费
Name	姓名
Transported	标签，是否被传送

**这是一个典型的表格分类任务，不是图像任务**，所以最常用的强模型其实是：

LightGBM
XGBoost
CatBoost
RandomForest
GradientBoosting

PyTorch 也可以做，但在这种表格数据上，神经网络不一定比树模型强。

### 3. 特征工程

这是这个比赛的重点。

#### 3.1 拆分 PassengerId

PassengerId 形如：

0001_01
0001_02
0002_01

可以拆成：

GroupId = 0001
PersonNum = 01

然后可以构造：

GroupSize = 同一个 GroupId 有多少人
IsAlone = 是否一个人旅行

这很有用，因为同一组乘客可能具有相似命运。

#### 3.2 拆分 Cabin

Cabin 形如：

B/0/P

可以拆成：

Deck = B
CabinNum = 0
Side = P

其中：

Deck 可能表示舱位区域
Side 可能表示船舱左右侧

这些通常和 Transported 有关系。

### 3.3 消费特征

原始消费列：

RoomService
FoodCourt
ShoppingMall
Spa
VRDeck

可以构造：

TotalSpend = 五项消费总和
NoSpend = 是否完全没有消费
LuxurySpend = RoomService + Spa + VRDeck
BasicSpend = FoodCourt + ShoppingMall

为什么有用？

因为处于 CryoSleep=True 的人通常消费为 0，所以消费和冷冻睡眠之间有强关系。

### 3.4 缺失值处理

数值特征可以填：

中位数
0

类别特征可以填：

Unknown

布尔特征可以填：

False

不过更好的做法是：

保留缺失信息

比如：

CryoSleep_missing = 1/0
VIP_missing = 1/0

因为“缺失本身”有时候也是一种信息。

## 4. 模型选择

这个项目可以分三档：

模型	适合程度
Logistic Regression	入门 baseline

LightGBM / XGBoost / CatBoost	Kaggle 表格赛常用强模型
PyTorch MLP	可以练神经网络流程，但不一定最强

def feature_engineering(df):
    df = df.copy()

    # 1. PassengerId 拆分
    df["GroupId"] = df["PassengerId"].str.split("_").str[0]
    df["PersonNum"] = df["PassengerId"].str.split("_").str[1].astype(int)

    # 2. 同组人数
    group_size = df.groupby("GroupId")["PassengerId"].transform("count")
    df["GroupSize"] = group_size
    df["IsAlone"] = (df["GroupSize"] == 1).astype(int)

    # 3. Cabin 拆分
    df[["Deck", "CabinNum", "Side"]] = df["Cabin"].str.split("/", expand=True)
    df["CabinNum"] = pd.to_numeric(df["CabinNum"], errors="coerce")

    # 4. 消费特征
    spend_cols = ["RoomService", "FoodCourt", "ShoppingMall", "Spa", "VRDeck"]

    for col in spend_cols:
        df[col] = df[col].fillna(0)

    df["TotalSpend"] = df[spend_cols].sum(axis=1)
    df["NoSpend"] = (df["TotalSpend"] == 0).astype(int)
    df["LuxurySpend"] = df["RoomService"] + df["Spa"] + df["VRDeck"]
    df["BasicSpend"] = df["FoodCourt"] + df["ShoppingMall"]

    # 5. 年龄分箱
    df["AgeBin"] = pd.cut(
        df["Age"],
        bins=[-1, 12, 18, 30, 50, 100],
        labels=["Child", "Teen", "Young", "Adult", "Senior"]
    ).astype(str)

    # 6. 删除不直接使用的字段
    df = df.drop(["PassengerId", "Name", "Cabin", "GroupId"], axis=1)

    return df

def train_one_epoch(model, loader, criterion, optimizer, device):
    model.train()

    total_loss = 0.0

    for X_batch, y_batch in loader:
        X_batch = X_batch.to(device)
        y_batch = y_batch.to(device)

        logits = model(X_batch)
        loss = criterion(logits, y_batch)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * X_batch.size(0)

    return total_loss / len(loader.dataset)

这一段是标准训练流程：

前向传播
计算 loss
梯度清零
反向传播
更新参数

验证函数：

def evaluate(model, loader, criterion, device):
    model.eval()

    total_loss = 0.0
    all_preds = []
    all_targets = []

    with torch.no_grad():
        for X_batch, y_batch in loader:
            X_batch = X_batch.to(device)
            y_batch = y_batch.to(device)

            logits = model(X_batch)
            loss = criterion(logits, y_batch)

            probs = torch.sigmoid(logits)
            preds = (probs > 0.5).long()

            total_loss += loss.item() * X_batch.size(0)
            all_preds.extend(preds.cpu().numpy())
            all_targets.extend(y_batch.cpu().numpy())

    avg_loss = total_loss / len(loader.dataset)
    acc = accuracy_score(all_targets, all_preds)

    return avg_loss, acc

## 九、这个项目面试中怎么讲？

你可以这样介绍：

我做的是 Kaggle Spaceship Titanic 二分类预测项目，目标是根据乘客的星球、舱位、消费、年龄、冷冻睡眠状态等信息预测乘客是否被传送。这个项目本质是一个表格二分类任务，我先做了数据分析，观察缺失值、类别分布和标签分布，然后进行了特征工程，比如从 PassengerId 中提取同行组信息，从 Cabin 中拆出 Deck、CabinNum、Side，并根据各项消费构造 TotalSpend、NoSpend 等特征。

在建模方面，我尝试了两条路线：一条是用 PyTorch 搭建 MLP，把类别特征 One-Hot 后和数值特征一起输入神经网络；另一条是使用 CatBoost 这类更适合表格数据的梯度提升树模型。对比后可以发现，PyTorch 更适合练深度学习训练流程，而 CatBoost 对类别特征和小规模表格数据更友好，通常更容易取得稳定效果。

## 十、面试官可能追问
问：为什么要拆 Cabin？

答：

因为 Cabin 原始字段是 Deck/CabinNum/Side 的组合，直接作为字符串用会损失结构信息。拆分后 Deck 可以表示甲板区域，Side 可以表示舱位侧边，CabinNum 可以表示舱位编号，这些都可能和 Transported 有关系。

问：为什么要从 PassengerId 提取 GroupSize？

答：

PassengerId 前半部分代表乘客所在 group，同一个 group 可能是同行人员或家庭成员，他们的行为和结果可能存在相关性。因此我提取 GroupId，并进一步构造 GroupSize 和 IsAlone，用来表示乘客是否独自旅行。

问：为什么消费特征重要？

答：

因为 CryoSleep 和消费之间有强关系。处于冷冻睡眠的乘客理论上不会产生 RoomService、FoodCourt、Spa 等消费，所以总消费金额和是否无消费可以间接反映乘客状态。TotalSpend 和 NoSpend 通常是比较有效的特征。

问：为什么 PyTorch 不一定比 CatBoost 好？

答：

因为这个任务是小规模表格数据，类别特征较多，样本量也不大。神经网络在表格数据上通常需要更多数据和更细致的调参，而 CatBoost、LightGBM 这类树模型对表格特征、类别变量、缺失值和非线性关系处理得更自然，所以更适合作为强 baseline。
