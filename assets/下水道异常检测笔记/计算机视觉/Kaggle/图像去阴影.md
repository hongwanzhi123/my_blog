# 图像阴影去除

## 一、图像去阴影任务是什么？

图像去阴影，英文叫：

Image Shadow Removal

它的目标是：

输入：带阴影图像 + 阴影掩码
输出：去除阴影后的自然图像

阴影会导致图像中局部区域出现：

亮度降低
颜色偏移
边界不连续
纹理信息被遮挡
局部结构不清晰

这不仅影响图像视觉质量，也会影响后续视觉任务，例如目标检测、跟踪、重光照等。你的第一篇论文中也明确指出，阴影会造成非均匀光照和颜色失真，并影响检测、跟踪、场景重光照等下游任务。

图像去阴影的核心难点在于：

阴影退化是局部的，但恢复所需的真实光照和颜色信息往往来自远处的非阴影区域。

也就是说，模型既要看清局部边界和纹理，又要理解全局光照和颜色一致性。

## 二、第一篇论文总结：Cross-Scale Collaborative Dual-Resolution Network for Shadow Removal
### 1. 研究动机

第一篇论文的核心出发点是：

现有方法很难同时兼顾局部结构细节和全局光照一致性。

传统 CNN 方法擅长建模局部纹理和边界，但受限于感受野，不容易利用远距离非阴影区域的信息。Transformer 虽然能建模长距离依赖，但普通自注意力容易把无关区域的信息混入阴影区域，导致边界模糊、颜色污染、残影等问题。你的论文中也提到，现有方法通常在单一尺度特征空间中混合细粒度结构和全局光照信息，没有充分利用阴影去除任务本身的多尺度特性。

因此第一篇论文提出：

Dual-Resolution Collaborative Encoding, DRCE
双分辨率协同编码框架

它的核心思想是：

高分辨率分支负责局部细节、边界、纹理
低分辨率分支负责全局光照、颜色一致性、稳定上下文
再通过 CSCF 模块进行跨尺度自适应融合
### 2. 整体架构

第一篇论文采用的是一个 U-shaped encoder-decoder 架构。

整体流程可以概括为：

带阴影图像 + 阴影 mask
↓
Input Projection
↓
编码器 Encoder
  - 浅层使用 DRCE Block
  - 深层使用 Basic Block
↓
解码器 Decoder
  - 上采样
  - skip connection
  - DRCE / Basic Block 细化
↓
Output Projection
↓
残差连接输出无阴影图像

论文中的 Fig. 1 展示了整体结构：输入阴影图像和 mask 先拼接，然后进入输入投影层，编码器中堆叠 DRCE Block 和 Basic Block，解码器通过上采样和跳跃连接恢复空间分辨率，最后输出去阴影结果。

这种 U-Net 风格结构适合图像恢复任务，因为它既能在编码器中提取语义和上下文信息，也能通过跳跃连接保留浅层细节。

### 3. DRCE：双分辨率协同编码模块

DRCE 是第一篇论文的核心模块。

它内部有两个分支：

High-Resolution Branch 高分辨率分支
Low-Resolution Branch 低分辨率分支
高分辨率分支

高分辨率分支直接在原始 feature map 上工作，重点保留：

阴影边界
局部纹理
高频结构
细粒度空间细节

论文中使用了：

Spatial Shuffle
+
Window-based Self-Attention
+
Inverse Shuffle

也就是先对空间 token 做 shuffle，让远距离 token 有机会被分到同一个 attention window 中，再做窗口注意力，最后 inverse shuffle 还原空间结构。这样既保留了 window attention 的计算效率，又增强了跨区域信息交互。

可以这样理解：

高分辨率分支负责“看清楚阴影边界和纹理细节”。

低分辨率分支

低分辨率分支先对输入特征进行下采样，例如 average pooling。因为分辨率降低后，每个 token 对应原图中更大的区域，所以它天然具有更大的感受野。

它重点建模：

全局光照趋势
整体颜色分布
低频上下文信息
非阴影区域对阴影区域的指导

你的论文中明确写到，低分辨率 token 对应原图中更大的感受野，因此适合建模全局低频上下文，例如整体光照趋势和连贯颜色分布。

可以这样理解：

低分辨率分支负责“判断整张图应该是什么光照和颜色”。

### 4. 为什么要用双分辨率？

图像去阴影本质上需要两种信息：

局部高频信息：边界、纹理、细节
全局低频信息：光照、颜色、语义上下文

如果只用高分辨率：

细节保留较好
但全局光照判断不稳定

如果只用低分辨率：

光照趋势较稳定
但边界和纹理容易变糊

所以 DRCE 的设计是：

高分辨率负责局部结构
低分辨率负责全局上下文
二者协同，而不是简单相加

这就是第一篇论文最重要的研究逻辑。

### 5. CSCF：跨尺度协同融合模块

有了高分辨率和低分辨率两个分支后，关键问题是：

如何让二者有效融合，而不是互相干扰？

第一篇论文提出了：

Cross-Scale Collaborative Fusion, CSCF
跨尺度协同融合模块

CSCF 的核心做法是：

一个低分辨率 token
对应原图中一块区域
它可以对应四个高分辨率 token
再加上自己这个低分辨率 token
组成 5-token group

也就是：

4 个高分辨率局部细节 token
+
1 个低分辨率全局上下文 token
↓
5-token group

然后通过轻量 MLP + Softmax 预测每个 token 的权重，动态决定当前区域更应该依赖局部细节，还是全局上下文。你的论文中也写到，CSCF 会收集同一低分辨率位置对应的四个高分辨率 token 和一个低分辨率 token，组成五个 token 的组合，并通过 MLP + softmax 生成融合权重。

简单说：

边界复杂区域 → 更多依赖高分辨率细节
大面积阴影区域 → 更多依赖低分辨率光照上下文
纹理区域 → 局部与全局共同参与

这比直接 concat 或 add 更合理，因为它是内容自适应的。

### 6. 第一篇论文的实验结果

第一篇论文在 SRD 和 ISTD+ 两个公开图像去阴影数据集上进行了实验。

它使用的指标包括：

RMSE：越低越好，衡量颜色误差
PSNR：越高越好，衡量重建质量
SSIM：越高越好，衡量结构相似性

论文结果显示，在 SRD 数据集上，整体区域 All 的 RMSE 达到 3.00，PSNR 达到 35.90 dB；在 ISTD+ 数据集上，整体区域 All 的 RMSE 达到 2.56，PSNR 达到 35.92 dB，说明模型在颜色恢复和整体重建质量上具有较强表现。

消融实验也说明，去掉 DRCE 或 CSCF 后性能会下降。尤其是在阴影区域，去掉低分辨率分支后 RMSE 从 4.63 上升到 4.92，PSNR 从 40.22 dB 下降到 39.51 dB，说明低分辨率全局上下文确实对阴影恢复有帮助。

### 7. 第一篇论文一句话总结

第一篇论文可以概括为：

针对图像去阴影中“局部细节恢复”和“全局光照一致性”难以兼顾的问题，提出 DRCE 双分辨率协同编码框架，通过高分辨率分支保留边界与纹理，通过低分辨率分支建模全局光照，再利用 CSCF 跨尺度 token 自适应融合，实现更自然、更稳定的阴影去除。

## 三、第二篇论文总结：Spatial Frequency Synergy for Shadow Removal
### 1. 研究动机

第二篇论文的思路和第一篇不同。

第一篇关注的是：

不同空间尺度之间如何协同

第二篇关注的是：

空间域和频率域之间如何协同

第二篇论文认为，现有去阴影方法大多在空间域中建模，也就是直接在图像特征图上做卷积、注意力或多尺度融合。这种方法的问题是：

光照变化和纹理结构被混在同一个空间特征中，模型没有显式区分“低频光照”和“高频纹理”。

你的第二篇论文摘要中明确指出，现有方法主要依赖空间域建模，往往不能显式分离光照变化和固有纹理，从而导致亮度不一致和阴影边界模糊。

因此第二篇提出：

Spatial Frequency Shadow Removal Network, SF-SRN
空间-频率协同阴影去除网络

它的核心思想是：

用空间分支建模结构上下文
用频率分支显式分解光照和纹理
再用 ASFF 模块自适应融合空间特征和频率特征
### 2. 整体架构

第二篇论文同样采用 U-Net 风格 encoder-decoder 结构，但在每个阶段引入了：

SFB：Spatial-Frequency Block
DFDB：Dynamic Frequency Decomposition Block
ASFF：Adaptive Spatial Frequency Fusion

整体流程可以概括为：

输入阴影图像 + mask
↓
Input Projection
↓
多阶段 Encoder
  - 每个阶段堆叠 SFB
  - Local Spatial Attention 建模空间上下文
  - DFDB 建模频率域光照/纹理
  - ASFF 融合空间与频率特征
↓
Bottleneck
↓
Decoder + Skip Connection
↓
Output Projection
↓
输出无阴影图像

论文 Fig. 1 展示了 SF-SRN 的整体架构：模型通过 ASFF 模块整合空间和频率表示，然后通过多尺度编码器-解码器和 skip connection 完成阴影恢复。

### 3. 空间分支：Local Spatial Context Modeling

空间分支使用类似 HomoFormer 的随机局部自注意力机制：

Spatial Shuffle
+
Window Attention
+
Inverse Shuffle

作用是：

建模阴影区域和非阴影区域之间的空间上下文关系
增强纹理对齐能力
增强局部对比度建模能力

这部分和第一篇的高分辨率分支有一定相似性，都是通过 shuffle window attention 扩展窗口注意力的有效感受野。

### 4. DFDB：动态频率分解模块

DFDB 是第二篇论文最核心的模块之一。

它的全称是：

Dynamic Frequency Decomposition Block
动态频率分解模块

它的目的不是简单做卷积，而是把特征显式分成：

低频分量：主要对应全局光照、亮度变化、颜色趋势
高频分量：主要对应纹理、边缘、结构细节

论文中写到，阴影会在不同频段中造成不同退化：低频主要编码全局光照变化，高频主要编码纹理和结构边缘，因此有效建模这两类互补信息对于同时实现光照一致性和细节保持非常重要。

### 5. DFDB 的具体流程

DFDB 的计算过程可以总结为：

输入特征 X
↓
FFT 转到频率域
↓
根据频率半径 R(u,v) 构建低频 / 高频软掩码
↓
得到低频频谱和高频频谱
↓
IFFT 回到空间域
↓
低频分支建模光照
↓
高频分支建模纹理
↓
DSConv 轻量编码
↓
GAP + Conv1×1 生成全局光照描述子
↓
调制融合后的频率特征

论文中 DFDB 先通过 FFT 将输入特征变换到频率域，然后根据频率半径构造可学习软掩码 Mlow 和 Mhigh，再通过 IFFT 得到低频和高频空间特征；低频分支关注全局光照结构，高频分支关注纹理与边缘，最后通过全局光照描述子调制融合后的频率表示。

这部分的价值在于：

不是让模型自己隐式学光照和纹理
而是主动提供一种“频域分解机制”
让模型更明确地处理低频光照和高频纹理
### 6. ASFF：自适应空间-频率融合模块

有了空间特征和频率特征后，第二篇论文同样面临融合问题：

什么时候更应该相信空间特征？
什么时候更应该相信频率特征？

因此提出：

Adaptive Spatial Frequency Fusion, ASFF
自适应空间-频率融合模块

ASFF 的核心思想是：

根据输入图像的纹理复杂度，动态调整空间分支和频率分支的贡献。

它先通过高频特征幅值估计一个频率重要性得分：

γ ∈ [0, 1]

如果 γ 大，说明图像中高频纹理丰富，需要更多关注频率分支；如果 γ 小，说明区域更平滑，可能更依赖低频光照和空间一致性。

然后 ASFF 构造 hybrid saliency map，并进行 Top-K 稀疏选择，只保留更重要的空间响应，最后通过 softmax gating 融合空间特征和频率特征。论文中也明确写到，ASFF 会根据高频特征幅值估计频率重要性分数，构造混合显著图，并使用自适应门控生成空间与频率分支的融合权重。

可以这样理解：

纹理丰富、边界复杂区域：
  更多利用高频纹理信息

大面积平滑阴影区域：
  更多利用低频光照信息

结构关系复杂区域：
  结合空间注意力进行上下文修正
### 7. 第二篇论文的实验结果

第二篇论文同样在 SRD 和 ISTD+ 上进行实验。

在 SRD 数据集上，SF-SRN 整体区域 All 达到：

RMSE：2.98
PSNR：35.94
SSIM：0.972

在 ISTD+ 数据集上，整体区域 All 达到：

RMSE：2.58
PSNR：35.92
SSIM：0.973

这些结果说明，空间-频率协同建模能够有效提升整体阴影去除质量。

消融实验进一步验证了 DFDB 和 ASFF 的作用。去掉 DFDB 后，ISTD+ 阴影区域 RMSE 从 4.69 上升到 4.92，PSNR 从 40.28 下降到 39.51；去掉 ASFF 后，阴影区域 RMSE 从 4.69 上升到 4.83，PSNR 从 40.28 下降到 39.96。这说明频率分解和空间-频率自适应融合都对性能有贡献。

### 8. 第二篇论文一句话总结

第二篇论文可以概括为：

针对现有空间域去阴影方法难以显式区分光照和纹理的问题，提出 SF-SRN 空间-频率协同框架，通过 DFDB 在频率域自适应分解低频光照和高频纹理，再通过 ASFF 动态融合空间上下文与频率信息，从而同时提升全局亮度一致性和局部结构恢复质量。

## 四、两篇论文的关系与区别

这两篇论文其实可以看作你在图像去阴影方向上的两个递进研究。

## 1. 共同点

两篇论文都关注图像去阴影中的核心矛盾：

局部阴影区域需要精细恢复
但恢复依据往往来自更大范围的上下文

它们都采用 encoder-decoder 框架，都使用 shadow image + mask 作为输入，也都强调：

边界清晰
颜色一致
光照自然
纹理不被破坏
## 2. 第一篇更关注“尺度”

第一篇的关键是：

高分辨率 = 局部细节
低分辨率 = 全局上下文
CSCF = 跨尺度选择性融合

它解决的是：

不同空间尺度的信息如何协同。

适合回答：

如何同时保留边界细节和全局光照一致性？
## 3. 第二篇更关注“频率”

第二篇的关键是：

低频 = 光照 / 亮度 / 色彩趋势
高频 = 纹理 / 边缘 / 结构细节
ASFF = 空间-频率自适应融合

它解决的是：

光照变化和纹理结构如何显式解耦。

适合回答：

为什么空间域方法容易边界模糊和亮度不一致？
如何用频域信息改善图像恢复？
## 4. 两篇论文对比表
维度	第一篇 DRCE	第二篇 SF-SRN
研究视角	空间尺度建模	空间域 + 频率域建模
核心矛盾	局部细节 vs 全局上下文	光照低频 vs 纹理高频
主体结构	双分辨率 encoder-decoder	空间-频率 U-Net
核心模块	DRCE、CSCF	DFDB、ASFF
关键机制	高低分辨率 token 协同融合	FFT 频率分解 + 空间频率门控融合
主要优势	边界细节和全局光照兼顾	显式分离光照与纹理，亮度更一致
可讲创新点	跨尺度 token grouping + adaptive weighting	adaptive frequency decomposition + spatial-frequency fusion
