# 基于经典网络模型进行构建训练图像分割模型的步骤

## 一、明确分割任务类型

图像分割主要分为三类：

### 1. 语义分割 Semantic Segmentation

每个像素预测一个类别，但不区分同类不同实例。

例如：

道路 / 天空 / 建筑 / 行人 / 车辆

如果图中有 3 辆车，语义分割只会标出它们都是“车”，不会区分第 1 辆、第 2 辆、第 3 辆。

常见模型：

FCN
U-Net
SegNet
DeepLabV3 / DeepLabV3+
PSPNet
HRNet
### 2. 实例分割 Instance Segmentation

不仅要知道像素属于什么类别，还要区分不同实例。

例如：

车1 / 车2 / 车3
人1 / 人2 / 人3

常见模型：

Mask R-CNN
YOLACT
SOLO
Mask2Former
### 3. 全景分割 Panoptic Segmentation

结合语义分割和实例分割。

既分割背景类：

天空、道路、草地

也分割实例类：

人1、人2、车1、车2

常见模型：

Panoptic FPN
Mask2Former

如果是一般项目、毕业设计、简历项目，通常从语义分割入手最合适。

## 二、准备数据集

图像分割数据集通常包含两部分：

原始图像 image
分割标签 mask

目录结构可以这样设计：

dataset/
 ├── images/
 │   ├── train/
 │   ├── val/
 │   └── test/
 └── masks/
     ├── train/
     ├── val/
     └── test/

例如：

images/train/001.jpg
masks/train/001.png

其中 mask 是对应的分割标注图。

## 三、理解 mask 标签格式

这是图像分割和图像分类最大的区别之一。

分类任务的标签通常是：

cat → 0
dog → 1
car → 2

而分割任务的标签是一个二维矩阵：

H × W

每个像素的值代表类别编号。

例如：

0 = background
1 = crack
2 = corrosion
3 = blockage

那么一张 mask 可能长这样：

[
 [0, 0, 0, 1, 1],
 [0, 0, 1, 1, 1],
 [0, 2, 2, 0, 0],
 [0, 2, 2, 0, 3]
]

含义是：

像素值为 0 的区域是背景
像素值为 1 的区域是裂缝
像素值为 2 的区域是腐蚀
像素值为 3 的区域是堵塞

需要注意：

图像是 RGB 三通道
mask 通常是单通道类别索引图

不要把 mask 当成普通彩色图片直接训练。

## 四、数据标注

图像分割需要像素级标注，常用标注工具有：

LabelMe
CVAT
Label Studio
Roboflow
Supervisely

常见标注形式：

多边形 polygon
画笔 brush
矩形框 + mask

标注完成后，需要将标注文件转换成模型需要的 mask 格式。

例如 LabelMe 标注后通常会得到：

xxx.json

需要转换成：

xxx.png

其中 xxx.png 的每个像素值是类别 ID。

## 五、数据划分

通常划分为：

训练集 train
验证集 val
测试集 test

比例可以是：

7 : 2 : 1

或者：

8 : 1 : 1

注意一点：

如果同一个场景、同一段视频、同一批设备拍摄的数据高度相似，划分时最好按场景或样本来源划分，而不是随机按图片划分。

否则可能出现：

训练集和测试集太像
测试结果虚高
实际泛化能力不好
## 六、图像预处理

分割模型一般要求 image 和 mask 同步处理。

例如：

image resize 到 512 × 512
mask 也必须 resize 到 512 × 512

但是要注意：

image resize 可以用双线性插值
mask resize 必须用最近邻插值

因为 mask 里面的像素值代表类别编号，如果用双线性插值，会产生不存在的类别值。

比如原来类别只有：

0, 1, 2

如果错误使用双线性插值，可能变成：

0.3, 1.5, 1.8

这是错误的。

## 七、数据增强

图像分割的数据增强必须保证 image 和 mask 同步变换。

常用增强包括：

随机水平翻转
随机垂直翻转
随机旋转
随机裁剪
随机缩放
颜色抖动
亮度变化
对比度变化
随机噪声

其中几何变换必须同时作用于 image 和 mask：

翻转 image，也要翻转 mask
旋转 image，也要旋转 mask
裁剪 image，也要裁剪 mask

而颜色增强只作用于 image，不作用于 mask。

推荐使用：

Albumentations

因为它很适合做图像分割增强。

示例：

import albumentations as A

train_transform = A.Compose([
    A.Resize(512, 512),
    A.HorizontalFlip(p=0.5),
    A.RandomRotate90(p=0.5),
    A.RandomBrightnessContrast(p=0.2),
])
## 八、选择经典分割模型

常见经典分割模型如下：

模型	特点	适合场景
FCN	最早的端到端语义分割网络之一	学习分割基础
U-Net	编码器-解码器结构，跳跃连接	医学图像、小数据集、缺陷检测
SegNet	编码器-解码器结构	语义分割基础实验
DeepLabV3	空洞卷积、多尺度上下文	自然场景分割
DeepLabV3+	Encoder-Decoder + ASPP	综合效果较好
PSPNet	金字塔池化，融合全局上下文	场景理解
HRNet	保持高分辨率特征	精细边界分割
Mask R-CNN	检测 + 实例 mask	实例分割

实际项目建议：

医学图像 / 缺陷检测 / 小数据集：U-Net、U-Net++
通用语义分割：DeepLabV3+、PSPNet
轻量化部署：MobileNetV3 + DeepLabV3
实例分割：Mask R-CNN

如果只是做一个简历项目，我建议优先选择：

U-Net + ResNet 编码器
DeepLabV3+ + ResNet/MobileNet backbone
Mask R-CNN
## 九、使用预训练 backbone

很多分割模型会把经典分类网络作为编码器。

例如：

ResNet
VGG
MobileNet
EfficientNet

在图像分类中，ResNet 最后输出一个类别。

在图像分割中，可以用 ResNet 前半部分提取特征，然后接一个 decoder，把特征图恢复到原图大小。

例如：

输入图像：512 × 512
↓
ResNet backbone 提取特征
↓
特征图：16 × 16 / 32 × 32
↓
Decoder 上采样
↓
输出 mask：512 × 512

最终输出不是一个类别，而是：

num_classes × H × W

例如 4 类分割：

输出 shape = [batch_size, 4, 512, 512]

每个像素位置都会有 4 个类别分数。

## 十、修改输出层

假设你的任务有 4 类：

0 = background
1 = crack
2 = corrosion
3 = blockage

那么模型最后一层输出通道数应该是：

num_classes = 4

对于 U-Net：

model = UNet(
    in_channels=3,
    num_classes=4
)

对于 DeepLabV3：

model.classifier[-1] = nn.Conv2d(
    in_channels=256,
    out_channels=num_classes,
    kernel_size=1
)

核心原则：

分类模型：最后输出 num_classes
分割模型：最后输出 num_classes × H × W
十一、设置损失函数
### 1. 多类别语义分割

如果每个像素只属于一个类别，通常使用：

nn.CrossEntropyLoss()

要求：

模型输出：[B, C, H, W]
mask 标签：[B, H, W]
mask 像素值：0 ~ C-1

示例：

criterion = nn.CrossEntropyLoss()
### 2. 二分类分割

如果只是前景 / 背景，比如：

背景
裂缝

可以使用：

nn.BCEWithLogitsLoss()

要求：

模型输出：[B, 1, H, W]
mask 标签：[B, 1, H, W]
mask 像素值：0 或 1
### 3. 类别不平衡问题

分割任务经常存在类别不平衡。

例如缺陷检测中：

背景像素占 98%
缺陷像素只占 2%

这时只用 CrossEntropyLoss 可能导致模型倾向于全部预测成背景。

可以使用：

Dice Loss
Focal Loss
Tversky Loss
CrossEntropy + Dice Loss
BCE + Dice Loss

常见组合：

loss = ce_loss + dice_loss

如果是缺陷、病灶、裂缝这类小目标分割，推荐：

Dice Loss + Focal Loss

或者：

CrossEntropyLoss + Dice Loss
## 十二、设置优化器和学习率

常用优化器：

Adam
AdamW
SGD

一般项目可以先用：

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=1e-4
)

学习率策略可以使用：

StepLR
CosineAnnealingLR
ReduceLROnPlateau
Warmup + Cosine
Poly LR

语义分割中也常用 Poly 学习率策略：

lr = base_lr × (1 - iter / max_iter) ^ power

但如果只是做项目或实验，使用余弦退火就可以：

scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=epochs
)
## 十三、训练模型

训练流程如下：

1. 读取 image 和 mask
2. 对 image 和 mask 做同步增强
3. image 输入模型
4. 得到预测分割图 logits
5. 计算预测结果和真实 mask 的 loss
6. 反向传播
7. 更新模型参数
8. 在验证集上计算指标
9. 保存最优模型

伪代码：

for epoch in range(epochs):
    model.train()

    for images, masks in train_loader:
        images = images.to(device)
        masks = masks.to(device)

        outputs = model(images)

        loss = criterion(outputs, masks)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    model.eval()

    with torch.no_grad():
        for images, masks in val_loader:
            images = images.to(device)
            masks = masks.to(device)

            outputs = model(images)
            preds = outputs.argmax(dim=1)

其中：

outputs.shape

通常是：

[B, num_classes, H, W]

而：

preds.shape

是：

[B, H, W]

表示每个像素预测出来的类别 ID。

## 十四、验证和评价指标

图像分割不能只看 Accuracy。

因为如果背景占 95%，模型全部预测背景，Accuracy 也可能很高。

常用指标包括：

Pixel Accuracy
Mean Pixel Accuracy
IoU
mIoU
Dice Coefficient
Precision
Recall
F1-score
Boundary F1

最常用的是：

mIoU
Dice
### 1. IoU

IoU 表示预测区域和真实区域的重叠程度。

IoU = 交集 / 并集

例如：

预测出的裂缝区域 ∩ 真实裂缝区域
--------------------------------
预测出的裂缝区域 ∪ 真实裂缝区域

IoU 越高，说明预测区域和真实区域越接近。

### 2. mIoU

mIoU 是对所有类别的 IoU 求平均。

mIoU = 所有类别 IoU 的平均值

语义分割论文和实验中，mIoU 是非常重要的指标。

### 3. Dice

Dice 也衡量预测区域和真实区域的重叠程度。

Dice = 2 × 交集 / (预测区域 + 真实区域)

Dice 在医学图像、缺陷检测、小目标分割中非常常见。

## 十五、保存最优模型

通常根据验证集上的指标保存模型。

例如：

val_mIoU 最大
或者 val_Dice 最大
或者 val_loss 最小

示例：

if val_miou > best_miou:
    best_miou = val_miou
    torch.save(model.state_dict(), "best_segmentation_model.pth")
## 十六、测试集评估

训练完成后，在测试集上评估最终效果。

测试集不能参与训练，也不能参与调参。

最终报告可以包括：

mIoU
Dice
Pixel Accuracy
每个类别的 IoU
每个类别的 Precision / Recall / F1
可视化预测结果

建议展示：

原图
真实 mask
预测 mask
错误区域对比图

这样比单纯写指标更有说服力。

## 十七、模型推理

推理流程：

1. 读取图片
2. Resize / Normalize
3. 输入模型
4. 得到 logits
5. argmax 得到每个像素类别
6. 将类别 ID 转换成颜色图
7. 叠加到原图上显示

示例：

model.eval()

with torch.no_grad():
    output = model(image)
    pred = output.argmax(dim=1)

如果是二分类分割：

prob = torch.sigmoid(output)
pred = (prob > 0.5).float()

如果是多类别分割：

pred = torch.argmax(output, dim=1)
## 十八、后处理

分割模型输出后，有时候还需要后处理。

常见后处理包括：

去除小连通区域
孔洞填充
边缘平滑
形态学开运算 / 闭运算
CRF 后处理
根据面积阈值过滤误检区域

例如缺陷检测中，可以过滤面积太小的误检：

如果预测区域面积 < 某个阈值，则认为是噪声
