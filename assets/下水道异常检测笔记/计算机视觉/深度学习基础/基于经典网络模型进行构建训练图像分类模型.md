# 基于经典网络模型进行构建训练图像分类模型

## 一、明确任务目标

首先要确定你要解决的是什么分类问题。

  输入：一张图片
  输出：图片所属类别

需要明确：

类别数量 num_classes
每个类别的数据量
是否是单标签分类还是多标签分类

## 二、准备数据集

train：训练集，用来训练模型
val：验证集，用来调参和观察是否过拟合
test：测试集，用来最终评估模型效果

常见划分比例：

训练集：70% / 80%
验证集：10% / 20%
测试集：10% / 20%

## 三、数据预处理

图像分类模型通常需要统一输入尺寸。

例如经典网络常用尺寸：

AlexNet：224 × 224
VGG：224 × 224
ResNet：224 × 224
MobileNet：224 × 224
EfficientNet：224 / 240 / 300 等

常见预处理包括：

Resize：调整图片大小
CenterCrop / RandomCrop：裁剪
ToTensor：转为张量
Normalize：归一化

## 四、数据增强

为了提升模型泛化能力，训练集通常要做数据增强。

常见增强方式：

随机裁剪
随机水平翻转
随机旋转
颜色抖动
随机缩放
随机擦除

验证集和测试集不要使用随机增强，一般只做固定预处理。

## 五、选择经典网络模型

模型	特点	适合场景
AlexNet	早期经典 CNN	学习 CNN 基础结构
VGG	结构简单，堆叠 3×3 卷积	适合教学、特征提取
GoogLeNet/Inception	多尺度卷积结构	适合复杂视觉特征
ResNet	残差连接，训练深层网络稳定	最常用的基准模型
DenseNet	特征复用能力强	数据量较小时也可尝试
MobileNet	轻量化网络	移动端、嵌入式部署
EfficientNet	精度和效率平衡较好	追求较高性能

实际项目中，建议优先从：

ResNet18 / ResNet34 / ResNet50
MobileNetV2 / MobileNetV3
EfficientNet-B0

## 六、使用预训练模型

一般不要从零开始训练经典网络，而是使用 ImageNet 预训练权重做迁移学习。

原因是：

训练更快
收敛更稳定
小数据集效果更好
模型已经学到了边缘、纹理、形状等通用视觉特征

以 ResNet 为例：

import torchvision.models as models
import torch.nn as nn

model = models.resnet50(pretrained=True)

num_features = model.fc.in_features
model.fc = nn.Linear(num_features, num_classes)

这里的关键是：

保留 ResNet 前面的特征提取层
替换最后的全连接分类层
让输出类别数等于自己的任务类别数

例如原本 ImageNet 是 1000 类，你自己的任务是 5 类，就要把最后一层改成：

nn.Linear(num_features, 5)

## 七、设置损失函数

单标签多分类任务通常使用：

criterion = nn.CrossEntropyLoss()

适用于：

一张图片只属于一个类别
输出是 num_classes 个 logits
标签是类别编号，比如 0、1、2、3

多标签分类任务通常使用：

criterion = nn.BCEWithLogitsLoss()

适用于：

一张图片可以属于多个类别
输出是 num_classes 个 logits
标签是 multi-hot 向量

例如：

[1, 0, 1, 0]

表示这张图片属于第 0 类和第 2 类。

## 八、设置优化器

常见优化器：

SGD
Adam
AdamW

一般建议：

optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=1e-4
)

如果使用 SGD：

optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
    momentum=0.9,
    weight_decay=1e-4
)

简单建议：

小数据集 / 快速实验：AdamW
经典论文复现 / 大规模训练：SGD + momentum

## 九、设置学习率策略

学习率对模型训练非常重要。

常见策略：

StepLR
CosineAnnealingLR
ReduceLROnPlateau
Warmup + Cosine

例如：

scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer,
    step_size=10,
    gamma=0.1
)

含义是：

每训练 10 个 epoch，学习率乘以 0.1

也可以使用余弦退火：

scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=epochs
)

## 十、训练模型

训练流程大致是：

1. 读取一个 batch 的图片和标签
2. 前向传播，得到预测结果
3. 计算 loss
4. 反向传播
5. 更新参数
6. 统计训练准确率和损失
7. 在验证集上评估模型
8. 保存最优模型

## 十一、验证模型效果

常见评价指标：

Accuracy：准确率
Precision：精确率
Recall：召回率
F1-score：综合指标
Confusion Matrix：混淆矩阵
AUC：二分类或多标签任务常用

如果类别均衡，Accuracy 可以作为主要指标。

如果类别不均衡，比如缺陷检测、疾病识别、异常检测，更建议看：

Precision
Recall
F1-score
F2-score
混淆矩阵

例如异常检测中，漏检代价很高，就要更加关注：

Recall
F2-score

因为 F2-score 更重视召回率。

## 十二、保存模型

一般保存效果最好的模型，而不是最后一个 epoch 的模型。

if val_acc > best_acc:
    best_acc = val_acc
    torch.save(model.state_dict(), "best_model.pth")

加载模型：

model.load_state_dict(torch.load("best_model.pth"))
model.eval()

## 十三、测试集评估

训练完成后，在测试集上做最终评估。

测试集不能参与训练，也不能用来调参。

流程：

加载 best_model.pth
在 test_loader 上推理
计算 Accuracy / Precision / Recall / F1
输出混淆矩阵

这样得到的结果才更接近模型真实泛化能力。

## 十四、模型推理

推理流程：

读取图片
做和验证集一样的预处理
送入模型
得到输出 logits
softmax 得到概率
取概率最大的类别作为预测结果
