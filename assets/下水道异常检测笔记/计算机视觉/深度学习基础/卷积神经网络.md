# 卷积神经网络

## 一、什么是卷积神经网络

卷积神经网络，全称是 Convolutional Neural Network，CNN，是一类特别适合处理图像数据的深度学习模型。

它最核心的思想是：

不直接把整张图片当成一长串数字去学习，而是通过“卷积核”在图像上滑动，逐步提取局部特征，比如边缘、纹理、形状、物体部件，最后完成分类、检测、分割等任务。

所以 CNN 的本质可以理解为：

用卷积层自动提取图像特征
用非线性激活增强表达能力
用池化或步幅降低特征图尺寸
用全连接层或分类头完成最终预测

## 二、为什么图像任务适合用 CNN

### 1. 图像具有局部相关性

图像中相邻像素往往关系更密切。

比如一个像素点和它周围的像素，可能共同构成一条边缘、一块纹理或者一个角点。

传统全连接网络会把图像直接拉平成一维向量：

224 × 224 × 3 → 150528 维向量

这样会破坏图像的空间结构。

CNN 不会这样做，它会保留图像的二维空间结构：

高度 H
宽度 W
通道 C

然后在局部区域上提取特征。

### 2. 图像特征具有平移不变性

假设一只猫出现在图片左上角，或者出现在图片右下角，它本质上还是猫。

CNN 通过卷积核共享参数，使得同一个特征检测器可以在整张图上重复使用。

比如一个“边缘检测卷积核”，可以在图片左边检测边缘，也可以在图片右边检测边缘。

这就是 CNN 很重要的优势：

同一个卷积核在不同位置共享参数
可以检测不同位置的相同模式

### 3. CNN 参数量比全连接网络少很多

如果用全连接层处理一张 224 × 224 × 3 的图片，并连接到 1000 个神经元，参数量大约是：

224 × 224 × 3 × 1000 = 150,528,000

也就是 1.5 亿个参数，非常大。

而一个卷积层如果使用 64 个 3 × 3 卷积核，输入通道是 3，那么参数量是：

3 × 3 × 3 × 64 = 1728

参数量小很多。

这就是 CNN 的两个核心优势：

局部连接
参数共享

## 三、CNN 的基本组成结构

一个典型 CNN 通常由以下部分组成：

输入图像
↓
卷积层 Convolution
↓
激活函数 ReLU
↓
池化层 Pooling
↓
多个卷积模块堆叠
↓
全连接层 / 分类头
↓
输出结果

例如：

Image
→ Conv
→ ReLU
→ MaxPool
→ Conv
→ ReLU
→ MaxPool
→ Flatten
→ FC
→ Softmax
→ Class

现代 CNN 通常更复杂，比如会加入：

BatchNorm
Residual Connection
Dropout
Global Average Pooling
Depthwise Separable Convolution
Attention

## 四、卷积层是什么？

卷积层是 CNN 最核心的部分。

它的作用是：

用一个小的卷积核在输入图像或特征图上滑动，对局部区域进行加权求和，从而提取局部特征。

假设输入是一张灰度图：

5 × 5

卷积核是：

3 × 3

卷积核会在图像上滑动，每次覆盖一个 3 × 3 的小区域，然后进行：

对应位置相乘，再求和

得到输出特征图上的一个值。

### 1. 卷积核可以理解成特征检测器

不同卷积核会学习不同特征。

比如有的卷积核可能学会检测：

水平边缘
垂直边缘
斜线
颜色变化
纹理
角点

随着网络训练，卷积核的参数会自动更新，不需要人工手写。

### 2. 卷积层的输出叫特征图

卷积之后得到的结果称为：

Feature Map，特征图

如果一个卷积层有 64 个卷积核，那么它会输出 64 张特征图。

例如输入：

224 × 224 × 3

经过一个卷积层：

Conv2D, out_channels = 64

输出可能是：

224 × 224 × 64

含义是：

每个位置有 64 种不同的特征响应

## 五、卷积层的重要参数

卷积层通常有几个关键参数。

### 1. Kernel Size：卷积核大小

常见卷积核大小：

1 × 1
3 × 3
5 × 5
7 × 7

最常见的是：

3 × 3

因为它参数少、效果好，而且堆叠多个 3 × 3 可以扩大感受野。

比如两个 3 × 3 卷积堆叠，感受野相当于一个 5 × 5，但参数更少，非线性表达能力更强。

### 2. Stride：步幅

步幅表示卷积核每次滑动多少个像素。

stride = 1：每次移动 1 个像素
stride = 2：每次移动 2 个像素

如果 stride 变大，输出特征图尺寸会变小。

例如：

输入 224 × 224
卷积 stride = 2
输出大约变成 112 × 112

所以 stride 可以起到降采样作用。

### 3. Padding：填充

Padding 是在图像边缘补 0。

如果不加 padding，卷积之后图像尺寸会变小。

例如：

输入 5 × 5
卷积核 3 × 3
stride = 1
padding = 0
输出 3 × 3

如果使用 padding：

输入 5 × 5
卷积核 3 × 3
stride = 1
padding = 1
输出 5 × 5

也就是保持尺寸不变。

常见写法：

3 × 3 卷积通常 padding = 1
5 × 5 卷积通常 padding = 2
7 × 7 卷积通常 padding = 3
### 4. Channel：通道数

图像通常有 RGB 三个通道：

H × W × 3

卷积核不仅有高度和宽度，还有输入通道维度。

比如输入是 RGB 图像，那么一个 3 × 3 卷积核实际参数是：

3 × 3 × 3

如果输出通道是 64，则有 64 个这样的卷积核。

参数量是：

3 × 3 × 3 × 64
### 5. 卷积输出尺寸计算公式

对于二维卷积，输出尺寸为：

Output = floor((Input + 2 × Padding - KernelSize) / Stride) + 1

例如：

Input = 224
KernelSize = 3
Padding = 1
Stride = 1

则：

Output = (224 + 2 × 1 - 3) / 1 + 1 = 224

所以输出尺寸不变。

如果：

Input = 224
KernelSize = 3
Padding = 1
Stride = 2

则：

Output = (224 + 2 × 1 - 3) / 2 + 1 = 112

输出尺寸减半。

## 六、激活函数 ReLU

卷积层本质上是线性运算，如果只堆叠卷积层，不加非线性激活函数，那么模型表达能力有限。

因此卷积后通常会接激活函数。

最常见的是：

ReLU

公式是：

ReLU(x) = max(0, x)

也就是：

如果 x > 0，保留 x
如果 x <= 0，变成 0

作用：

引入非线性
缓解梯度消失
加快训练收敛
增强网络表达能力

例如：

nn.ReLU()

现代网络中也可能使用：

Leaky ReLU
PReLU
GELU
SiLU / Swish

但经典 CNN 中 ReLU 最常见。

## 七、池化层 Pooling

池化层用于降低特征图尺寸，减少计算量，同时增强一定的平移鲁棒性。

常见池化方式：

Max Pooling
Average Pooling
Global Average Pooling
### 1. Max Pooling

最大池化是在局部区域中取最大值。

例如 2 × 2 最大池化：

输入区域：
1  3
2  4

输出：
4

它保留最明显的特征响应。

常见配置：

kernel_size = 2
stride = 2

作用是把特征图尺寸减半：

224 × 224 → 112 × 112
112 × 112 → 56 × 56
### 2. Average Pooling

平均池化是在局部区域中取平均值。

它更关注整体平均响应，而不是最强响应。

### 3. Global Average Pooling

全局平均池化常用于现代 CNN 分类模型中。

比如最后的特征图是：

7 × 7 × 2048

Global Average Pooling 会对每个通道的 7 × 7 空间区域求平均，得到：

1 × 1 × 2048

然后再接分类层。

相比 Flatten + 全连接层，Global Average Pooling 参数更少，不容易过拟合。

## 八、Batch Normalization

BatchNorm 是现代 CNN 中非常常见的结构。

通常结构是：

Conv → BatchNorm → ReLU

BatchNorm 的作用是对中间特征进行归一化，使训练更加稳定。

主要作用：

加快收敛
缓解梯度不稳定
允许使用更大的学习率
具有一定正则化效果

例如 PyTorch 写法：

nn.BatchNorm2d(num_features)

其中 num_features 通常等于输出通道数。

## 九、全连接层和分类头

在图像分类任务中，CNN 前面部分负责提取特征，最后需要输出类别概率。

早期模型常用：

Flatten → Fully Connected → Softmax

例如：

特征图：7 × 7 × 512
Flatten 后：25088
全连接层：25088 → 4096 → 4096 → 1000

这是 VGG 的典型做法。

现代模型更多使用：

Global Average Pooling → Linear

例如 ResNet：

7 × 7 × 2048
↓
Global Average Pooling
↓
2048
↓
Linear(2048, num_classes)

最后输出：

num_classes 个 logits

训练时通常使用：

CrossEntropyLoss

推理时再通过：

Softmax

得到每个类别的概率。

## 十、CNN 的层级特征学习过程

CNN 最大的特点是逐层抽象。

### 1. 浅层特征

靠近输入的卷积层通常学习：

边缘
角点
颜色变化
简单纹理

这些特征比较通用。

### 2. 中层特征

中间层会学习更复杂的局部模式：

纹理组合
局部形状
物体部件
轮廓结构

例如：

眼睛
轮子
窗户
叶片
管道裂缝纹理
### 3. 深层特征

深层会学习高级语义：

猫脸
汽车
行人
建筑
缺陷区域
病灶区域

所以在迁移学习中，通常认为：

浅层特征更通用
深层特征更任务相关

这也是为什么我们可以用 ImageNet 预训练模型迁移到自己的任务上。

## 十二、CNN 为什么能够自动提取特征？

传统图像识别方法通常需要人工设计特征，比如：

SIFT
HOG
LBP
Haar
颜色直方图
纹理特征

这种方法的问题是：

特征设计依赖专家经验
迁移到新任务不一定有效
复杂场景表达能力有限

CNN 的优势是：

特征由数据驱动自动学习
浅层到深层逐级抽象
端到端训练
可以直接从原始图像学习到任务相关特征

比如在缺陷检测任务中，不需要人工定义“裂缝纹理特征”，CNN 可以通过大量样本自动学习哪些纹理、边缘、形状与裂缝相关。

## 十三、经典 CNN 网络结构

下面介绍几个经典网络。

### 1. LeNet

LeNet 是早期 CNN 代表模型，主要用于手写数字识别。

结构大致是：

Conv
Pool
Conv
Pool
FC
FC
Output

特点：

结构简单
证明了卷积网络在图像识别中的有效性
适合入门理解 CNN
### 2. AlexNet

AlexNet 是深度学习图像识别爆发的重要模型。

特点：

使用更深的 CNN
使用 ReLU
使用 Dropout
使用数据增强
使用 GPU 训练

它让 CNN 在大规模图像分类任务中取得突破性效果。

结构大致是：

Conv → Pool
Conv → Pool
Conv
Conv
Conv → Pool
FC
FC
FC
### 3. VGG

VGG 的核心思想是：

大量堆叠 3 × 3 卷积

比如 VGG16 有 16 个带参数层。

特点：

结构规整
容易理解
适合作为特征提取 backbone
参数量较大
计算开销较大

VGG 的一个重要贡献是证明了：

用多个小卷积核堆叠，可以替代大卷积核，并获得更强表达能力

例如两个 3 × 3 卷积相当于一个 5 × 5 感受野，但参数更少，非线性更多。

### 4. GoogLeNet / Inception

Inception 的核心思想是：

在同一层使用多种尺度卷积，然后把结果拼接起来

例如：

1 × 1 卷积
3 × 3 卷积
5 × 5 卷积
池化

这样可以让网络同时捕捉不同尺度的特征。

特点：

多尺度特征提取
使用 1 × 1 卷积降低计算量
参数效率较高
结构相对复杂
### 5. ResNet

ResNet 是非常重要的经典网络。

它提出了：

残差连接 Residual Connection

普通网络学习的是：

H(x)

ResNet 让网络学习：

F(x) = H(x) - x

最后输出：

H(x) = F(x) + x

结构可以理解为：

输入 x
↓
卷积层
↓
卷积层
↓
加回 x
↓
输出

也就是：

y = F(x) + x

残差连接解决了深层网络难训练的问题。

特点：

可以训练很深的网络
缓解梯度消失
收敛更稳定
迁移学习中非常常用

常见版本：

ResNet18
ResNet34
ResNet50
ResNet101
ResNet152

实际项目中，ResNet 是非常常用的 baseline。

### 6. DenseNet

DenseNet 的核心思想是：

每一层都连接到后面的所有层

也就是特征不断复用。

特点：

特征复用强
梯度传播好
参数效率较高
但特征拼接会带来显存开销
### 7. MobileNet

MobileNet 主要面向移动端和轻量化部署。

它使用：

Depthwise Separable Convolution

也就是深度可分离卷积。

普通卷积同时做：

空间特征提取 + 通道融合

MobileNet 把它拆成两步：

Depthwise Convolution：每个通道单独做空间卷积
Pointwise Convolution：用 1 × 1 卷积做通道融合

这样可以大幅减少参数量和计算量。

适合：

移动端
嵌入式
实时推理
轻量级图像分类
轻量级分割 backbone
### 8. EfficientNet

EfficientNet 的核心思想是平衡缩放：

网络深度 depth
网络宽度 width
输入分辨率 resolution

它不是单纯加深或加宽网络，而是综合调整三者。

特点：

精度和效率平衡较好
适合做强 baseline
参数效率高

## 十四、CNN 在不同视觉任务中的作用

CNN 不只用于图像分类，还可以作为很多视觉任务的基础。

### 1. 图像分类

任务：

输入一张图片
输出一个类别

例如：

猫 / 狗 / 鸟
正常 / 缺陷
裂缝 / 腐蚀 / 堵塞

常用模型：

VGG
ResNet
DenseNet
MobileNet
EfficientNet
### 2. 目标检测

任务：

判断图中有什么物体
并给出物体位置框

输出包括：

类别
边界框 bbox
置信度

常见模型：

Faster R-CNN
SSD
YOLO
RetinaNet

CNN 在目标检测中通常作为 backbone 提取特征。

### 3. 图像分割

任务：

对每个像素分类

常见模型：

FCN
U-Net
DeepLab
PSPNet
Mask R-CNN

CNN 用于提取局部和语义特征，再通过上采样恢复空间分辨率。

### 4. 图像生成和修复

CNN 也常用于：

图像去噪
超分辨率
图像修复
图像增强
风格迁移

例如 U-Net 就常用于图像修复、医学图像分割、扩散模型中的去噪网络等。

## 十五、CNN 的核心优势

CNN 的优势主要有：

能够保留图像空间结构
通过局部连接减少参数量
通过参数共享提升泛化能力
自动学习多层次图像特征
适合分类、检测、分割等视觉任务
可以结合预训练模型进行迁移学习

总结成一句话：

CNN 能够用较少的参数，从图像中自动学习从低级纹理到高级语义的层级特征，因此非常适合计算机视觉任务。

## 十六、CNN 的局限性

CNN 也不是完美的。

### 1. 对全局关系建模能力有限

卷积主要关注局部区域，虽然深层网络可以通过堆叠扩大感受野，但它天然更擅长局部模式。

对于长距离依赖、全局上下文关系，CNN 不如 Transformer 直接。

### 2. 对旋转、尺度变化仍然敏感

CNN 有一定平移不变性，但对旋转、尺度、遮挡、光照变化等仍然需要依赖：

数据增强
更强的模型结构
更多训练数据
### 3. 对数据质量依赖较强

如果数据集存在：

标注错误
类别不均衡
背景偏差
训练测试分布差异

CNN 也容易学到错误模式。

例如模型可能不是学到了“缺陷特征”，而是学到了某种拍摄背景或设备水印。

### 4. 可解释性较弱

CNN 能学到有效特征，但很难完全解释每个卷积核到底学到了什么。

常用解释方法包括：

Grad-CAM
Feature Map 可视化
Occlusion Test
Class Activation Map

## 十七、CNN 和 Transformer 的区别

近年来视觉 Transformer 很流行，比如 ViT、Swin Transformer。

两者区别可以这样理解：

对比项	CNN	Vision Transformer
核心操作	卷积	Self-Attention
擅长	局部特征	全局关系
归纳偏置	强，有局部性和平移共享	弱，更依赖数据
小数据表现	通常较好	可能更依赖预训练
计算特点	对高分辨率图像较友好	全局注意力计算量较大
代表模型	ResNet、VGG、MobileNet	ViT、Swin、DeiT

CNN 的优势是：

更符合图像局部结构
小数据集更容易训练
工程部署成熟
计算效率高

Transformer 的优势是：

全局建模能力强
适合大规模预训练
在很多任务上上限高

现在很多模型会结合二者，比如：

CNN backbone + Attention
ConvNeXt
Swin Transformer
Hybrid CNN-Transformer
