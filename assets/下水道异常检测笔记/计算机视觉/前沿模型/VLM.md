# VLM 视觉语言模型

VLM（Vision-Language Model）是视觉语言模型，用于建立图像、文本以及多模态语义之间的对应关系。传统视觉模型通常只处理图像分类、检测或分割，而 VLM 更强调“视觉内容”和“自然语言描述”的统一表达。

## 一、基本定义

VLM 的核心目标是让模型同时理解图像和文本。输入可以是图像、文本或图文组合，输出可以是类别、描述、检索结果、问答结果或定位结果。

常见任务包括：

- 图文检索：根据文本找图像，或根据图像找文本。
- 图像描述：生成图像内容的自然语言描述。
- 视觉问答：根据图像回答文本问题。
- 开放词表分类：使用文本类别描述完成分类。
- 开放词表检测与分割：根据文本提示定位或分割目标。

## 二、核心思想

VLM 的关键是把视觉特征和文本特征映射到同一个语义空间。图像编码器负责提取视觉表示，文本编码器负责提取语言表示，然后通过对比学习、交叉注意力或生成式训练实现跨模态对齐。

以 CLIP 为代表的对比学习方法，会让匹配的图文对在特征空间中更接近，不匹配的图文对更远。这样模型可以在没有固定分类头的情况下，利用文本提示完成 zero-shot 分类。

生成式 VLM 则通常把图像特征输入到大语言模型中，使语言模型能够基于视觉信息生成回答、描述或推理结果。

## 三、典型结构

VLM 常见结构可以分为三类。

双塔结构由图像编码器和文本编码器分别提取特征，再计算相似度。该结构适合图文检索和开放词表分类，推理效率较高。

融合结构会在中间层使用 cross-attention 让图像 token 和文本 token 交互，适合需要细粒度理解的任务，例如视觉问答、图文推理。

生成式结构通常使用视觉编码器提取图像特征，再通过投影层接入大语言模型。该结构适合多轮问答、图像理解和复杂推理。

## 四、训练目标

VLM 的训练目标通常包括以下几类：

- 图文对比学习：对齐匹配图像和文本。
- 图文匹配：判断图像和文本是否对应。
- 掩码语言建模：根据视觉上下文恢复文本。
- 图像描述生成：根据图像生成说明文本。
- 指令微调：让模型按照自然语言指令完成任务。

不同训练目标对应不同能力。对比学习更适合检索和 zero-shot 识别，生成式训练更适合理解和问答，指令微调更适合交互式应用。

## 五、应用场景

VLM 可用于通用视觉理解，也可以作为下游视觉任务的辅助模块。

在分类任务中，可以用文本 prompt 构造类别描述，实现开放词表分类。在检测和分割任务中，可以用文本指定目标类别，例如“找出图像中的裂纹区域”。在工业视觉中，VLM 可以辅助异常描述、数据检索和标注检查。在医学图像中，VLM 可以连接影像区域和诊断文本，但需要更严格的数据质量和安全约束。

## 六、局限性

VLM 的能力依赖大规模图文数据，但互联网图文数据存在噪声、偏见和语义不精确的问题。模型可能学到表面相关性，而不是严格的视觉因果关系。

此外，VLM 在细粒度定位、计数、空间关系、专业领域知识和低资源场景中仍然容易出错。生成式 VLM 还可能产生幻觉，即输出看似合理但与图像内容不一致的文字。

## 七、知识总结

VLM 的本质是跨模态语义对齐。它把图像理解从封闭类别扩展到开放语言空间，使视觉模型能够利用自然语言表达任务需求。

从方法体系看，CLIP 类模型强调图文对齐和 zero-shot 能力，融合式模型强调细粒度交互，生成式模型强调自然语言理解和推理。VLM 的优势是开放性强、迁移能力好，但在专业场景中仍需要结合任务数据、评估指标和人工校验机制。
