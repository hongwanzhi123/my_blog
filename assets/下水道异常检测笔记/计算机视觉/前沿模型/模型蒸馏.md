# 模型蒸馏

模型蒸馏，也叫 Knowledge Distillation，知识蒸馏，是一种模型压缩和迁移技术。它的核心思想是：

用一个大模型、强模型作为 Teacher Model，去指导一个小模型、轻量模型 Student Model 学习，让小模型在保持较低计算量的同时，尽量接近大模型的效果。

简单说就是：

大模型效果好，但推理慢、部署成本高
↓
小模型速度快，但精度可能低
↓
用大模型教小模型
↓
得到一个又快又相对准确的小模型

## 一、为什么需要模型蒸馏？

在真实项目里，训练模型和部署模型往往不是同一个诉求。

训练时通常希望模型：

精度高
表达能力强
泛化好
可以用大 backbone
可以用 ensemble
可以用大输入尺寸

但部署时通常希望模型：

速度快
显存占用低
模型文件小
延迟低
能跑在 CPU / 边缘设备 / 移动端 / 工控机

比如做工业视觉检测，训练时可以用：

YOLO11x
Swin Transformer
Mask2Former
ConvNeXt-Large
多个模型融合

但真实部署在工控机上，可能只能接受：

YOLO11n / YOLO11s
MobileNet
EfficientNet-B0
轻量 U-Net
INT8 ONNX Runtime

这时候就可以用蒸馏：

让大模型负责提供更丰富、更稳定的监督信号，小模型学习大模型的判断方式，从而提升小模型效果。

## 二、传统训练和蒸馏训练的区别
1. 普通监督训练

普通训练是：

输入图像
↓
Student Model
↓
预测结果
↓
和真实标签 Ground Truth 计算 loss
↓
更新 Student

例如分类任务中，真实标签是：

这张图是猫

标签通常是 one-hot：

cat: 1
dog: 0
car: 0
bird: 0

模型只知道：

正确类别是 cat
其他类别都是错的
2. 蒸馏训练

蒸馏训练多了一个 Teacher：

输入图像
↓
Teacher Model → teacher output
↓
Student Model → student output
↓
Student 同时学习：
    1. 真实标签 Ground Truth
    2. Teacher 的输出分布 / 特征 / 注意力 / 中间层信息

也就是：

Loss = 真实标签监督 loss + 蒸馏 loss

例如：

Loss = CE(student, label) + KL(student, teacher)

Student 不只是学“正确答案”，还学 Teacher 对类别之间关系的理解。

## 三、为什么 Teacher 的输出比 one-hot 标签更有信息？

这是模型蒸馏最核心的理解点。

假设有一张图片是数字 3。

真实标签 one-hot 是：

0: 0
1: 0
2: 0
3: 1
4: 0
5: 0
6: 0
7: 0
8: 0
9: 0

它只告诉模型：

这是 3

但 Teacher 的输出可能是：

0: 0.01
1: 0.01
2: 0.04
3: 0.82
4: 0.01
5: 0.03
6: 0.01
7: 0.01
8: 0.05
9: 0.01

这里包含更多信息：

Teacher 认为它主要是 3
但也有一点像 8
还有一点像 2
不像 0、1、4、7

这种类别之间的相似关系，叫：

dark knowledge，暗知识

它比 one-hot 标签更柔和，也更有结构信息。

对于目标检测也是类似：

Teacher 不只是告诉这个框是什么类别
还可以告诉哪些框更可信
哪些区域可能是难例
类别之间的混淆关系是什么
特征层中哪里更重要

## 四、模型蒸馏的基本组成

模型蒸馏通常有三个部分：

Teacher Model：教师模型，大模型，性能强
Student Model：学生模型，小模型，部署友好
Distillation Loss：蒸馏损失，让 Student 模仿 Teacher
1. Teacher Model

Teacher 通常是：

大模型
高精度模型
训练充分的模型
多个模型 ensemble
带更大输入尺寸的模型

例如：

ResNet101 教 ResNet18
ConvNeXt-Large 教 MobileNet
YOLO11x 教 YOLO11s
Mask2Former 教 U-Net
大尺寸模型教小尺寸模型
多模型融合结果教单模型

Teacher 一般已经训练好了，在蒸馏时通常冻结参数：

teacher.eval()
for p in teacher.parameters():
    p.requires_grad = False
2. Student Model

Student 是最终要部署的模型。

它通常更小：

参数更少
FLOPs 更低
推理速度更快
显存占用更少

例如工业视觉中：

Teacher: YOLO11x-seg
Student: YOLO11s-seg

Teacher: DeepLabv3+ ResNet101
Student: U-Net MobileNet

Teacher: Swin Transformer
Student: MobileNetV3
3. Distillation Loss

蒸馏损失负责约束 Student 学 Teacher。

常见蒸馏信号包括：

输出 logits
类别概率分布
中间特征 feature map
attention map
检测框预测
mask 预测
relation / similarity matrix

所以蒸馏可以分很多类型。

## 五、最经典的蒸馏：Logits 蒸馏

Logits 蒸馏是最基础、最经典的方式。

1. 什么是 logits？

分类模型最后一层输出的原始分数叫 logits。

例如：

logits = [1.2, -0.5, 3.1, 0.8]

经过 softmax 后变成概率：

prob = softmax(logits)
2. 普通 softmax

普通 softmax 是：

p_i = exp(z_i) / sum(exp(z_j))

如果某个类别 logits 很大，softmax 后会非常接近 1。

这会让概率分布很尖锐。

3. Temperature 温度系数

蒸馏里通常会引入温度系数 T：

p_i = softmax(z_i / T)

当 T = 1，就是普通 softmax。

当 T > 1，概率分布会变得更平滑。

比如原来 Teacher 输出：

cat: 0.98
dog: 0.01
fox: 0.01

提高温度后可能变成：

cat: 0.70
dog: 0.18
fox: 0.12

这样 Student 可以学到：

虽然是 cat，但 dog 和 fox 也有一定相似性

这就是蒸馏中常说的 soft label。

4. Logits 蒸馏损失

常见形式：

L_kd = KLDiv(
    softmax(student_logits / T),
    softmax(teacher_logits / T)
)

总损失：

L = α * CE(student_logits, hard_label)
  + β * T² * KL(student_logits/T, teacher_logits/T)

其中：

CE：学生和真实标签的交叉熵
KL：学生分布和教师分布之间的差异
T：温度
α、β：两个 loss 的权重

一般要乘 T²，是为了补偿温度带来的梯度缩放影响。

## 六、PyTorch 分类蒸馏代码示例

假设存在 Teacher 和 Student 两个分类模型。

import torch
import torch.nn as nn
import torch.nn.functional as F


class DistillationLoss(nn.Module):
    def __init__(self, alpha=0.5, temperature=4.0):
        super().__init__()
        self.alpha = alpha
        self.temperature = temperature
        self.ce_loss = nn.CrossEntropyLoss()
        self.kl_loss = nn.KLDivLoss(reduction="batchmean")

    def forward(self, student_logits, teacher_logits, labels):
        T = self.temperature

        # 真实标签监督
        hard_loss = self.ce_loss(student_logits, labels)

        # Teacher soft label 蒸馏
        student_log_probs = F.log_softmax(student_logits / T, dim=1)
        teacher_probs = F.softmax(teacher_logits / T, dim=1)

        soft_loss = self.kl_loss(student_log_probs, teacher_probs) * (T * T)

        loss = self.alpha * hard_loss + (1 - self.alpha) * soft_loss

        return loss

训练流程：

teacher.eval()
student.train()

criterion = DistillationLoss(alpha=0.5, temperature=4.0)
optimizer = torch.optim.AdamW(student.parameters(), lr=1e-3)

for images, labels in train_loader:
    images = images.to(device)
    labels = labels.to(device)

    with torch.no_grad():
        teacher_logits = teacher(images)

    student_logits = student(images)

    loss = criterion(student_logits, teacher_logits, labels)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

这里关键点是：

with torch.no_grad():
    teacher_logits = teacher(images)

Teacher 只负责提供监督信号，不更新参数。

## 七、模型蒸馏的几种主要类型

模型蒸馏不止 logits 蒸馏。

常见类型有：

1. Response-based Distillation：响应蒸馏
2. Feature-based Distillation：特征蒸馏
3. Relation-based Distillation：关系蒸馏
4. Attention-based Distillation：注意力蒸馏
5. Self-distillation：自蒸馏
6. Online Distillation：在线蒸馏
7. Data-free Distillation：无数据蒸馏

下面分别讲。

## 八、Response-based Distillation 响应蒸馏

这是最经典的蒸馏方式。

它让 Student 模仿 Teacher 的最终输出。

分类任务中：

Teacher logits / probabilities
↓
Student logits / probabilities
↓
KL loss

目标检测中：

Teacher 的分类分数
Teacher 的 bbox 预测
Teacher 的 objectness
↓
Student 模仿

分割任务中：

Teacher 的 mask logits
↓
Student 的 mask logits
↓
像素级 KL / MSE / BCE

优点：

实现简单
适合分类任务
不需要修改模型结构

缺点：

只利用最终输出
没有充分利用 Teacher 的中间特征
检测/分割任务中效果可能不够

## 九、Feature-based Distillation 特征蒸馏

特征蒸馏让 Student 学习 Teacher 的中间特征。

比如 Teacher 和 Student 都有 feature map：

Teacher feature: [B, C_t, H, W]
Student feature: [B, C_s, H, W]

如果通道数不同，需要加一个 adapter：

Student feature
↓
1x1 Conv
↓
对齐到 Teacher feature 维度

然后计算：

L_feature = MSE(student_feature, teacher_feature)
1. 为什么特征蒸馏有用？

因为 Teacher 的中间层特征包含很多视觉信息：

边缘
纹理
局部结构
目标形状
语义区域
上下文关系

Student 直接学最终类别，可能学得不够细。

如果让 Student 学 Teacher 的 feature map，就能更好地学习 Teacher 的表示能力。

2. 特征蒸馏代码示例
class FeatureDistiller(nn.Module):
    def __init__(self, student_channels, teacher_channels):
        super().__init__()
        self.adapter = nn.Conv2d(student_channels, teacher_channels, kernel_size=1)
        self.loss = nn.MSELoss()

    def forward(self, student_feat, teacher_feat):
        student_feat = self.adapter(student_feat)

        if student_feat.shape[-2:] != teacher_feat.shape[-2:]:
            student_feat = F.interpolate(
                student_feat,
                size=teacher_feat.shape[-2:],
                mode="bilinear",
                align_corners=False
            )

        return self.loss(student_feat, teacher_feat.detach())

总 loss：

L = CE + λ * FeatureLoss

## 十、Attention-based Distillation 注意力蒸馏

注意力蒸馏不是直接让 Student 复制所有特征，而是让 Student 学 Teacher “关注哪里”。

例如一个 feature map：

[B, C, H, W]

可以把通道维度聚合成 attention map：

attention = mean(abs(feature), dim=channel)

得到：

[B, 1, H, W]

然后让 Student 的 attention map 接近 Teacher 的 attention map。

1. 为什么注意力蒸馏适合视觉任务？

因为对于图像任务，Teacher 可能知道：

哪里是目标区域
哪里是背景
哪里是缺陷区域
哪里是重要纹理

Student 学 Teacher 的注意力，可以更快聚焦关键区域。

2. 注意力图蒸馏示例
def attention_map(feat):
    # feat: [B, C, H, W]
    att = feat.abs().mean(dim=1, keepdim=True)

    # 归一化
    att = att / (att.norm(p=2, dim=(2, 3), keepdim=True) + 1e-6)

    return att


def attention_distill_loss(student_feat, teacher_feat):
    s_att = attention_map(student_feat)
    t_att = attention_map(teacher_feat)

    if s_att.shape[-2:] != t_att.shape[-2:]:
        s_att = F.interpolate(
            s_att,
            size=t_att.shape[-2:],
            mode="bilinear",
            align_corners=False
        )

    return F.mse_loss(s_att, t_att.detach())

## 十一、Relation-based Distillation 关系蒸馏

关系蒸馏不只是让 Student 学单个样本的输出，而是学 Teacher 对样本之间关系的理解。

例如一个 batch 里有多张图片，Teacher 提取 embedding：

T1, T2, T3, ..., TN

计算样本之间相似度矩阵：

S_teacher[i, j] = similarity(T_i, T_j)

Student 也计算：

S_student[i, j]

然后让两个相似度矩阵接近：

L_relation = MSE(S_student, S_teacher)

这种方式适合：

度量学习
人脸识别
图像检索
ReID
CLIP 类图文对齐
表示学习

## 十二、Self-distillation 自蒸馏

自蒸馏是：

没有单独的大 Teacher，模型自蒸馏。

常见形式：

深层输出教浅层输出
历史模型教当前模型
同一个模型不同增强视角互相学习
EMA teacher 教 student

比如 Mean Teacher：

Student 模型正常训练
Teacher 是 Student 参数的指数滑动平均 EMA
Teacher 生成更稳定的伪标签
Student 学 Teacher

这种方式常用于：

半监督学习
自监督学习
小数据训练
医学图像
工业缺陷检测

## 十三、Online Distillation 在线蒸馏

传统蒸馏通常是：

先训练 Teacher
再训练 Student

在线蒸馏是：

Teacher 和 Student 同时训练
多个 Student 互相学习

例如有多个模型：

Model A
Model B
Model C

它们同时训练，每个模型既学习真实标签，也学习其他模型的平均预测。

优点：

不需要预训练 Teacher
多个模型互相促进

缺点：

训练复杂
显存和计算开销更大

## 十四、Data-free Distillation 无数据蒸馏

有时候存在 Teacher 模型，但没有原始训练数据。

比如：

公司只给一个大模型
原始数据因为隐私不能提供

这时候可以用数据生成方法生成伪样本，再让 Student 学 Teacher。

这叫 Data-free Distillation。

常见思路：

随机噪声初始化图片
↓
优化图片，让 Teacher 对它有高置信度
↓
得到 synthetic data
↓
用 synthetic data 蒸馏 Student

或者用生成模型生成数据。

这个方向偏研究，工程中不如普通蒸馏常见。

## 十五、模型蒸馏在图像分类中的应用

图像分类蒸馏最简单。

流程：

Teacher: ResNet101 / ConvNeXt / ViT
Student: ResNet18 / MobileNet / EfficientNet-B0
↓
输入同一张图
↓
Teacher 输出 soft logits
Student 输出 logits
↓
CE + KL 蒸馏训练

典型 loss：

L = α * CE(student, label)
  + β * KL(student/T, teacher/T)

图像分类中，logits 蒸馏通常就能有效提升小模型。

## 十六、模型蒸馏在目标检测中的应用

目标检测蒸馏比分类复杂很多。

因为目标检测输出不仅有类别，还有：

bbox
objectness
multi-scale feature
dense predictions
positive / negative samples

检测蒸馏通常包括：

1. 分类分支蒸馏
2. bbox 回归分支蒸馏
3. objectness 蒸馏
4. FPN 多尺度特征蒸馏
5. foreground 区域蒸馏
6. attention 蒸馏
1. 为什么检测蒸馏更难？

分类任务输出一个类别分布：

[B, num_classes]

检测任务输出大量候选位置：

[B, anchors, classes + bbox + objectness]

其中大部分位置是背景。

如果直接对所有位置蒸馏，背景区域太多，会干扰训练。

所以检测蒸馏通常更关注：

foreground 区域
高置信度区域
GT bbox 附近区域
Teacher 认为重要的区域
2. YOLO 蒸馏可以怎么做？

以 YOLO 为例，可以设计：

Teacher: YOLO11x
Student: YOLO11s

蒸馏内容：

1. Student 学真实标签的 YOLO loss
2. Student 学 Teacher 的分类 logits
3. Student 学 Teacher 的 objectness
4. Student 学 Teacher 的 bbox 输出
5. Student 学 Teacher neck 的多尺度特征

总 loss：

L = L_yolo_gt
  + λ_cls * L_cls_kd
  + λ_obj * L_obj_kd
  + λ_box * L_box_kd
  + λ_feat * L_feature_kd

实际工程中，很多时候不从零实现 YOLO 蒸馏，而是使用已有框架或做更简单的伪标签蒸馏。

## 十七、伪标签蒸馏 Pseudo-label Distillation

这是检测任务里非常实用的一种方式。

流程：

1. 用大 Teacher 对训练集 / 无标签数据进行预测
2. 保留高置信度预测框
3. 把这些预测结果当作伪标签
4. 用真实标签 + 伪标签训练 Student

比如：

Teacher YOLO11x
↓
对大量未标注图片预测
↓
筛选 confidence > 0.6 的框
↓
生成 YOLO label txt
↓
训练 YOLO11s

优点：

实现简单
不需要改 YOLO loss
可以利用无标签数据
适合目标检测

缺点：

伪标签有噪声
Teacher 错误会传给 Student
置信度阈值需要调

对于当前做 Kaggle/工业视觉，这种方式比复杂 feature distillation 更容易落地。

## 十八、模型蒸馏在语义分割中的应用

分割任务输出的是像素级预测：

[B, C, H, W]

Teacher 和 Student 都输出 mask logits。

可以做：

1. 像素级 logits 蒸馏
2. 特征图蒸馏
3. 边界区域蒸馏
4. 注意力图蒸馏
5. 类别关系蒸馏
1. 像素级 logits 蒸馏

Teacher 输出：

teacher_logits: [B, C, H, W]

Student 输出：

student_logits: [B, C, H, W]

使用：

KLDivLoss(student/T, teacher/T)

这相当于每个像素都学习 Teacher 的类别分布。

2. 边界蒸馏

分割中边界很重要。

Teacher 通常能给出更平滑、更准确的边界。

Student 可以重点学习边界区域。

例如：

从 GT mask 或 Teacher mask 提取边界
↓
只在边界附近区域计算蒸馏 loss

适合：

医学分割
工业缺陷分割
牙齿病灶分割
裂纹分割

## 十九、模型蒸馏在大模型中的应用

现在大语言模型也大量使用蒸馏。

例如：

Teacher: GPT-4 / 大参数模型
Student: 小语言模型

蒸馏方式：

1. 用 Teacher 生成高质量问答数据
2. Student 用这些数据做 supervised fine-tuning
3. Student 学 Teacher 的推理风格、回答格式、任务能力

这类蒸馏不一定直接拿 logits，有时是用 Teacher 生成的数据进行训练。

也就是：

response distillation
rationale distillation
instruction distillation

不过当前主要关注视觉算法，了解即可。

## 二十、蒸馏和迁移学习的区别

这两个概念容易混。

迁移学习

迁移学习通常是：

用预训练模型参数初始化
↓
在目标数据集上 fine-tune

例如：

ImageNet 预训练 ResNet
↓
在工业缺陷数据上微调

它主要是“迁移参数”。

模型蒸馏

模型蒸馏是：

Teacher 输出监督信号
↓
Student 学 Teacher 的行为

它主要是“迁移知识”。

区别：

对比项	迁移学习	模型蒸馏
核心	使用预训练权重	使用 Teacher 监督 Student
是否需要 Teacher 推理	通常不需要	需要
目标	提升目标任务训练效果	压缩模型 / 提升小模型
学习内容	参数初始化	输出分布、特征、关系、注意力

## 二十一、蒸馏和剪枝、量化的区别

模型压缩有很多方式：

蒸馏
剪枝
量化
低秩分解
轻量结构设计
1. 蒸馏
大模型教小模型

目标是提升小模型效果。

2. 剪枝
删除不重要的通道、权重、层

目标是减少模型计算量。

3. 量化
FP32 → INT8 / FP16

目标是减少模型大小，提高推理速度。

4. 它们可以组合

实际部署中经常是：

训练大模型 Teacher
↓
蒸馏训练小模型 Student
↓
导出 ONNX
↓
FP16 / INT8 量化
↓
ONNX Runtime / TensorRT 部署

这条链路非常适合写进工业视觉项目。

## 二十二、蒸馏的优点
1. 提升小模型精度
2. 降低部署成本
3. 保留大模型部分泛化能力
4. 可以利用无标签数据
5. 可以用于模型压缩
6. 可以提升训练稳定性
7. 可以缓解 one-hot 标签信息不足
二十三、蒸馏的缺点
1. 需要一个训练好的 Teacher
2. 训练流程更复杂
3. Teacher 太差会误导 Student
4. Teacher 和 Student 差距太大时不好学
5. 蒸馏 loss 权重需要调
6. 检测/分割蒸馏实现复杂
7. 蒸馏不一定总能提升效果

特别注意：

Teacher 越强越好，但 Teacher 和 Student 差距太大时，Student 可能学不动。

比如：

Teacher: 超大 ViT-L
Student: 极小 MobileNet

这时直接 logits 蒸馏可能效果一般，需要 feature adapter、逐层蒸馏或中间 Teacher。

常见超参数：

训练 epoch
学习率
1. Temperature

常用：

T = 2, 4, 6, 8

分类任务可以从：

T = 4

开始试。

2. Alpha / Beta

常见：

如果数据标签质量高，hard loss 可以更大。

如果 Teacher 很强，soft loss 可以加大。

特征蒸馏不要一开始权重太大。

可以从：

试起。

## 二十六、在项目中怎么用模型蒸馏？

结合当前关注的方向，可这样落地。

1. 手写数字识别项目

可以做：

Teacher: 较强 CNN
Student: 小 CNN / MLP / CTM-like 小模型
蒸馏方式: logits distillation

可以对比：

Student 普通训练 accuracy
Student 蒸馏训练 accuracy

这很适合学习蒸馏。

2. 工业缺陷分类项目

可以做：

Teacher: ConvNeXt-Tiny / ResNet50
Student: MobileNetV3 / EfficientNet-B0

蒸馏方式：

CE + KL logits 蒸馏
feature map 蒸馏
attention map 蒸馏

资料可以写：

引入知识蒸馏，将 ConvNeXt Teacher 的类别分布和中间特征迁移到 MobileNet Student，在保持轻量化推理的同时提升小模型缺陷分类准确率。
3. YOLO 目标检测项目

常用先做伪标签蒸馏：

Teacher: YOLO11x
Student: YOLO11s

流程：

Teacher 训练到较高精度
↓
Teacher 对训练集/额外数据推理
↓
筛选高置信度伪标签
↓
真实标签 + 伪标签训练 Student
↓
Student 导出 ONNX 部署

这比直接修改 YOLO 内部 loss 简单很多。

4. 牙齿分割 AlphaDent 项目

可以做：

Teacher: yolo11m-seg / yolo11l-seg
Student: yolo11s-seg

实际路线：

1. 用大模型训练/推理生成高质量 mask 伪标签
2. 用真实标签 + Teacher 伪标签训练小模型
3. 对比 Student 普通训练和蒸馏训练的提交分数
4. 最后导出 ONNX 做部署

如果时间有限，先不要做复杂 feature distillation，先做伪标签蒸馏。

## 二十七、模型蒸馏 核心总结

核心说明：

模型蒸馏是一种模型压缩和知识迁移方法，核心思想是用一个性能更强的 Teacher Model 去指导一个轻量 Student Model 训练，使 Student 在保持较低参数量和推理成本的同时，尽量接近 Teacher 的效果。

最经典的是 logits 蒸馏。Teacher 输出的不是 one-hot 标签，而是更软的类别概率分布，其中包含类别之间的相似关系，也叫 dark knowledge。训练时 Student 一方面学习真实标签的交叉熵 loss，另一方面通过 KL 散度学习 Teacher 的 soft logits，通常还会引入 temperature 让概率分布更平滑。

除了 logits 蒸馏，还有 feature-based distillation、attention distillation 和 relation distillation。对于分类任务，logits 蒸馏通常就比较有效；对于目标检测和分割任务，通常还需要蒸馏中间特征、FPN 多尺度特征、前景区域或 mask logits。

在部署场景中，蒸馏常用于把大模型能力迁移到小模型上，比如用 YOLO11x 教 YOLO11s，或者用 ConvNeXt Teacher 教 MobileNet Student。蒸馏后的小模型可以进一步导出 ONNX，并结合 ONNX Runtime、TensorRT 或量化部署到实际环境中。

## 二十八、延伸知识：为什么 soft label 有用？

核心说明：

one-hot 标签只告诉模型哪个类别是正确的，但 Teacher 的 soft label 还能反映类别之间的相似性。例如一张 3 的手写数字图片，Teacher 可能认为它 80% 是 3，10% 像 8，5% 像 2。这种分布包含了 Teacher 对样本结构和类别关系的理解，比硬标签更丰富。Student 学习这种分布后，通常泛化能力更好。

## 二十九、延伸知识：蒸馏的 loss 怎么写？

核心说明：

常见总损失由两部分组成：一部分是 Student 和真实标签之间的交叉熵，另一部分是 Student 和 Teacher soft logits 之间的 KL 散度。一般形式是：

L = α * CE(student_logits, y) + β * T² * KL(student_logits/T, teacher_logits/T)

其中 T 是 temperature，用来平滑概率分布，α 和 β 控制硬标签监督和软标签蒸馏的权重。
